# No-Project Learning Path Maintenance Checklist

Date: 2026-04-30

Use this checklist before adding or changing no-project learning files.

## Required Boundaries

Every no-project page must state or preserve these boundaries:

- no active game project is required;
- do not invent a project;
- do not invent playtest data;
- do not invent player reactions;
- do not invent telemetry;
- do not parse private or high-risk source bodies;
- do not summarize copyrighted chapters;
- do not claim verified source-backed knowledge without EvidenceRefs and review.

## Required Artifact Footer

Every no-project artifact should include:

| Field | Required |
|---|---|
| artifact_type | yes |
| source_basis | yes |
| confidence | yes |
| assumptions | yes |
| evidence_gaps | yes |
| not_claimed | yes |
| next_action | yes |

## Exercise Requirements

Each exercise must include:

- input;
- AI prompt;
- output artifact;
- completion checklist;
- source/confidence rule.

## Plan Requirements

Each day or session should include:

- what to do;
- what to ask AI;
- what artifact to create;
- what to read or inspect;
- what note to write;
- what not to overclaim.

## Reject The Change If

Reject or revise any no-project change that:

- implies a hypothetical project is real;
- implies a hypothetical playtest happened;
- uses invented participant behavior;
- claims player reaction without evidence;
- promotes an artifact to verified;
- asks the AI to read private source bodies;
- asks the AI to summarize book chapters;
- omits source_basis or confidence.
