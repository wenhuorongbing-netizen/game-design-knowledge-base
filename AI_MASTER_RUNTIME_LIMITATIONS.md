# AI Master Runtime Limitations

Date: 2026-04-29

## Purpose

This file states what the AI Master Runtime can and cannot honestly do right now.

## Current Strengths

The runtime can:

- route design problems to capabilities;
- select lenses and workflows;
- produce design artifacts;
- teach source-bounded concepts;
- ask high-value diagnostic questions;
- create reading note prompts;
- identify evidence gaps;
- refuse unsafe source requests;
- prepare benchmark runs and score real outputs.

## Current Limitations

| Limitation | Meaning |
|---|---|
| No verified source-backed masterclass yet | Most framework content is draft/source-governed, not verified doctrine. |
| No user reading notes yet | The AI cannot claim user interpretations or source-backed book insights. |
| No legal sidecars yet | Private/high-risk source bodies remain out of bounds. |
| No active game project required | The AI can help with concepts and learning, but cannot invent project facts. |
| No real playtest logs | The AI can plan tests but cannot report results. |
| Benchmark not behaviorally scored | Scoreboards are `not_tested` until real target outputs exist. |

## What The AI Can Still Do Without A Project

- critique a game idea;
- define a core experience hypothesis;
- teach concepts;
- generate diagnostic questions;
- run draft lens reviews;
- create prototype questions;
- suggest reading routes;
- prepare exercises;
- map evidence gaps.

## What The AI Must Not Claim

- that a book says something unless evidence exists;
- that private source content was read;
- that a design will work with players;
- that a market will respond positively;
- that a playtest happened;
- that a claim is verified without EvidenceRef;
- that generated advice is source-backed doctrine.

## How To Communicate Limitations

Use direct language:

- "This is a draft design scaffold, not a verified source claim."
- "No user notes currently support this book-specific claim."
- "I can produce a playtest plan, but not playtest results."
- "This recommendation is a weak hypothesis until tested."
