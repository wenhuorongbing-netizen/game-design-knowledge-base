# Worked Demo Examples

Date: 2026-04-30

## Purpose

This folder shows how a user can apply the hands-on prompts without needing to understand the full repository.

These are examples of output shape, not evidence.

## Safety Status

Every worked example is labeled:

- demo_only
- synthetic_example
- not_user_evidence
- not_project_evidence
- not_benchmark_result
- not_verified_claim

## What These Examples Are

They are fictional demonstrations of:

- how to give the AI a usable input;
- which prompt to use;
- what kind of artifact the AI should produce;
- how assumptions, source_basis, confidence, and evidence gaps should be shown;
- how to adapt an output for real use.

## What These Examples Are Not

They are not:

- real user projects;
- real playtest records;
- real source evidence;
- real benchmark outputs;
- verified game design claims;
- summaries of private books;
- quotations from source texts.

## How To Use

1. Pick the example closest to your situation.
2. Open the linked hands-on prompt.
3. Replace the fictional user input with your real input.
4. Keep the same safety footer.
5. Treat the AI output as draft guidance unless real evidence is supplied.
