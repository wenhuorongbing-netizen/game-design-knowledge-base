# Hands-On Prompt Selection Guide

Use this when you do not know which prompt to choose.

## Fast Decision Table

| User situation | Use prompt | Why |
|---|---|---|
| I only have an idea. | [P01 Review My Game Idea](hands_on_prompts/P01_review_my_game_idea.md) | Turns a rough idea into a concept memo. |
| I know the idea but not the experience. | [P02 Define Core Experience](hands_on_prompts/P02_define_core_experience.md) | Clarifies player feeling, promise, and pillars. |
| I do not know what to ask. | [P03 Generate Design Questions](hands_on_prompts/P03_generate_design_questions.md) | Creates expert diagnostic questions. |
| I want critique from multiple angles. | [P04 Run Lens Review](hands_on_prompts/P04_run_lens_review.md) | Selects lenses and produces review findings. |
| My choices feel fake. | [P05 Audit Meaningful Decisions](hands_on_prompts/P05_audit_meaningful_decisions.md) | Builds a decision audit matrix. |
| My system or economy is messy. | [P06 Audit Systems And Economy](hands_on_prompts/P06_audit_systems_and_economy.md) | Maps resources, loops, and risks. |
| My game feels floaty or weak. | [P07 Audit Game Feel And Feedback](hands_on_prompts/P07_audit_game_feel_and_feedback.md) | Separates input, response, context, and polish. |
| My UI or HUD is confusing. | [P08 Audit UI Feedback](hands_on_prompts/P08_audit_ui_feedback.md) | Reviews information priority and feedback clarity. |
| Story and mechanics do not fit. | [P09 Align Narrative And Mechanics](hands_on_prompts/P09_align_narrative_and_mechanics.md) | Maps action to narrative meaning. |
| I need to test an assumption. | [P10 Make Prototype Plan](hands_on_prompts/P10_make_prototype_plan.md) | Creates a prototype question sheet. |
| I need to test with players. | [P11 Make Playtest Plan](hands_on_prompts/P11_make_playtest_plan.md) | Creates a playtest plan without inventing results. |
| I want to learn a topic. | [P12 Teach Me Game Design](hands_on_prompts/P12_teach_me_game_design.md) | Produces a mini lesson and exercise. |
| I want to read books safely. | [P13 Create Reading Plan](hands_on_prompts/P13_create_reading_plan.md) | Gives metadata-level reading routes and note prompts. |
| I worry a claim is unsupported. | [P14 Check Unsupported Claim](hands_on_prompts/P14_check_unsupported_claim.md) | Produces a claim safety report. |
| My pitch is weak. | [P15 Pitch Critique](hands_on_prompts/P15_pitch_critique.md) | Reviews promise, hook, proof, and risk. |

## If You Are Still Unsure

Use P03 first. Good questions often reveal which design artifact is needed next.

## If Your Input Is Very Short

Use P01, P02, or P03. These prompts can proceed with labeled assumptions.

## If Your Input Is Concrete

Use P04 through P11. These prompts work best when you can provide an idea, mechanic, loop, UI, prototype, or playtest question.

## If You Need Learning Instead Of Design Work

Use P12 or P13.

## If You Need Source Safety

Use P14. Do not ask the AI to cite a book unless EvidenceRefs exist.
