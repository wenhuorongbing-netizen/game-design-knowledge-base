# Worked Examples Folder

Date: 2026-04-30

## What This Folder Is

This folder contains synthetic demonstrations of how to use the hands-on prompt pack.

These examples are for learning the interaction pattern only.

## What This Folder Is Not

This folder is not:

- a project evidence folder;
- a benchmark output folder;
- a source evidence folder;
- a verified claim folder;
- a private book summary folder.

## Safety Rule

Treat every file here as:

- demo_only;
- synthetic_example;
- not_user_evidence;
- not_project_evidence;
- not_benchmark_result;
- not_verified_claim.

## Start Here

Use the root index first:

- [../WORKED_EXAMPLES_README.md](../WORKED_EXAMPLES_README.md)

Then open the example closest to your current problem.
