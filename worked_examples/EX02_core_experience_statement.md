# EX02 - Core Experience Statement

Labels: demo_only, synthetic_example, not_user_evidence, not_project_evidence, not_benchmark_result, not_verified_claim.

## User Input

My game is about a tiny robot cleaning up a ruined greenhouse. I want it to feel peaceful but not boring.

## Prompt Used

[P02_define_core_experience.md](../hands_on_prompts/P02_define_core_experience.md)

## Example AI Output

| Section | Synthetic output |
|---|---|
| player promise | Restore a fragile place through small, careful actions that make the greenhouse visibly recover. |
| core experience statement | The player should feel gentle competence: each tiny cleanup or repair makes the greenhouse healthier and reveals a new small possibility. |
| core loop | Notice a problem, choose a cleanup or repair action, spend limited battery, see plant or machine feedback, unlock a nearby micro-goal. |
| emotional target | Peaceful, attentive, lightly strategic. |
| friction target | Low danger, but enough scarcity to make the next action matter. |
| output artifact | Core experience card plus three design pillars. |

## Why This Output Is Useful

It separates theme from playable experience. The output gives the AI and designer a stable target for later audits.

## Assumptions

- Battery or time limits create lightweight pressure.
- The player sees immediate and delayed feedback.
- The greenhouse is the central space.
