# EX07 - Narrative-Mechanic Alignment

Labels: demo_only, synthetic_example, not_user_evidence, not_project_evidence, not_benchmark_result, not_verified_claim.

## User Input

The story says the sea spirits are lonely, but mechanically the player only collects items for them.

## Prompt Used

[P09_align_narrative_and_mechanics.md](../hands_on_prompts/P09_align_narrative_and_mechanics.md)

## Example AI Output

| Narrative promise | Current mechanic | Alignment issue | Redesign option | Artifact to create |
|---|---|---|---|---|
| spirits are lonely | fetch items | loneliness becomes shopping list | add memory-sharing, ritual timing, or repeated visits | spirit interaction pattern |
| relationship grows | one-time delivery | no social continuity | track trust through choices and return visits | trust state diagram |
| lighthouse restoration matters emotionally | repair checklist | repair may feel separate from spirits | tie a repair to a spirit memory or need | repair-to-story map |

## Why This Output Is Useful

It identifies where story claims are not supported by player action and turns them into redesign options.

## Assumptions

- Spirit relationships are central, not optional flavor.
- The game can support repeated interaction.
- The user wants mechanics to express theme.

## What This Example Does Not Prove

It does not prove the new mechanics will create emotional attachment. It only aligns player action with stated narrative intent.

## How User Can Adapt It

List one story promise, the current player action, and the desired feeling. Ask the AI to produce a narrative-mechanic alignment table.
