# EX01 - Vague Game Idea Review

Labels: demo_only, synthetic_example, not_user_evidence, not_project_evidence, not_benchmark_result, not_verified_claim.

## User Input

I want to make a cozy survival game where the player repairs an abandoned lighthouse, gathers driftwood, and talks to sea spirits.

## Prompt Used

[P01_review_my_game_idea.md](../hands_on_prompts/P01_review_my_game_idea.md)

## Example AI Output

| Section | Synthetic output |
|---|---|
| concept memo | A low-pressure repair and relationship game about restoring a lighthouse so the coast feels safer, warmer, and more inhabited. |
| core experience | Calm responsibility: the player makes small daily repairs and sees the world become safer and more responsive. |
| repeated action | Explore shore, gather modest resources, choose one repair or spirit interaction, receive visible environmental feedback. |
| design pillars | Gentle survival pressure; repair as emotional restoration; spirits as interactive needs rather than exposition. |
| lenses | Core Experience, Feedback Timing, Scope Control, Narrative-Mechanic Alignment, Meaningful Routine. |
| risks | Survival pressure may fight the cozy tone; spirits may become dialogue vending machines; repair scope may become too large. |
| next artifact | One-page concept memo with 3 repair verbs, 3 spirit verbs, and 1 day loop. |

## Why This Output Is Useful

It turns a vague fantasy into a draft player promise, repeated action, risk list, and next artifact.

## Assumptions

- The game is intended to feel cozy rather than punishing.
- Daily action limits create lightweight tradeoffs.
- Repair changes are visible in the world.
