# 30-Day Foundation Plan

Date: 2026-04-29

## Purpose

This plan gives a non-overwhelming first month for learning the core of game design and using the AI Master Framework safely.

## Four-Week Plan

| Week | Capability Focus | Recommended Works | Concepts To Learn | Lenses To Use | Workflows To Run | Exercises To Complete | User Notes To Create | AI Prompts To Try | Output Artifact |
|---|---|---|---|---|---|---|---|---|---|
| 1 | What is game design and core experience? | The Art of Game Design; Game Design Workshop | game, player, experience goal, player fantasy, scope | Core Experience; Audience; Scope | Game Idea to One-Page Concept Pack; Core Experience Definition Pack | Ideation Exercise 01; Ideation Exercise 02 | one note on what a designer decides; one note on player fantasy | review game idea; define core experience | One-page concept and core experience statement |
| 2 | Rules, mechanics, and meaningful decisions | Rules of Play; Game Mechanics | rules, mechanics, objectives, resources, meaningful decisions, tradeoffs | Rule Clarity; Meaningful Decisions; Tradeoffs | Rules and Formal Elements Pack; Meaningful Decision Audit Pack | Rules / Mechanics Exercise 01; Meaningful Decision Exercise 01 | one note on a good decision; one note on a fake choice | meaningful decision audit; generate design questions | Formal elements sheet and decision matrix |
| 3 | Systems, economy, challenge | Advanced Game Design; Game Mechanics; Characteristics of Games | system, loop, feedback, source, sink, balance, challenge | Parts/Loops/Whole; Feedback Loops; Source/Sink Balance | Systems Map Pack; Economy and Balance Pack | Systems / Economy Exercise 01; Systems / Economy Exercise 02 | one note on a system loop; one note on a reward economy | systems audit; economy audit | System map and economy map |
| 4 | Feedback, prototype, playtest | Game Feel; Level Up; Game Design Workshop | game feel, UI feedback, prototype question, playtest observation | Input Responsiveness; Information Priority; Prototype Question; Playtest Signal | Game Feel Prototype Pack; UI Feedback Pack; Prototype Question Pack; Playtest Plan Pack | Game Feel Exercise 01; UI / Feedback Exercise 01 | one note on feel; one note on playtest planning | game feel audit; UI feedback audit; create playtest plan | Prototype and test plan |

## Completion Criteria

- Four artifacts created.
- Eight short user notes created.
- At least four AI prompts tested.
- No unsupported claim promoted to verified.
