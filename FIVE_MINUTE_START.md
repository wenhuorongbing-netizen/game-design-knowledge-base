# Five-Minute Start

Date: 2026-04-30

## Goal

Get one useful artifact in five minutes.

## Minute 1: Pick One Situation

Choose one:

- no project;
- vague idea;
- design review;
- learn game design;
- check a claim.

If unsure, choose "vague idea" if you have any idea at all. Choose "no project" if you do not.

## Minute 2: Open One Context Pack

- no project: [CP03 learning coach](context_packs/CP03_learning_coach.md)
- vague idea: [CP02 game idea review](context_packs/CP02_game_idea_review.md)
- design review: [CP04 design audit](context_packs/CP04_design_audit.md)
- learn game design: [CP03 learning coach](context_packs/CP03_learning_coach.md)
- check a claim: [CP06 source safety](context_packs/CP06_source_safety_and_claim_check.md)

Do not open the whole repository.

## Minute 3: Copy One Prompt

- no project: [P12 teach me game design](hands_on_prompts/P12_teach_me_game_design.md)
- vague idea: [P01 review my game idea](hands_on_prompts/P01_review_my_game_idea.md)
- design review: [P04 run lens review](hands_on_prompts/P04_run_lens_review.md)
- learn game design: [P12 teach me game design](hands_on_prompts/P12_teach_me_game_design.md)
- check a claim: [P14 check unsupported claim](hands_on_prompts/P14_check_unsupported_claim.md)

Copy only the "Copy-Paste Prompt" section.

## Minute 4: Paste Your Input

Use a short input:

- idea: 1 to 5 sentences;
- review: what you want reviewed and what worries you;
- learning: topic and level;
- claim: exact claim plus evidence you have, or `none`.

Write `unknown` where needed.

## Minute 5: Check The Output

The answer must include:

- one artifact;
- assumptions;
- source_basis;
- confidence;
- evidence gaps;
- next action.

If it does not, paste the rerun prompt from [ACCESSIBLE_FIRST_USE_CHECKLIST.md](ACCESSIBLE_FIRST_USE_CHECKLIST.md).

## Stop Condition

Stop when you have one artifact and one next action.

Do not keep browsing.
