# Progressive Disclosure Model

Date: 2026-04-30

## Purpose

This model keeps the repository usable by revealing only the files needed for the user's current task.

## Core Rule

Do not browse the whole repo.

Start with one level. Move deeper only when the task requires it.

## Levels At A Glance

| Level | Name | Who uses it | Open by default? |
|---|---|---|---|
| 0 | one page only | first-time human user | yes |
| 1 | first-use files | normal users | yes |
| 2 | use-case files | users with a task | yes after choosing a task |
| 3 | context packs and prompts | AI agents and users copying prompts | yes for AI-assisted work |
| 4 | runtime and framework reference | advanced AI/runtime work | only when needed |
| 5 | governance, benchmark, validation, schemas | maintainers and auditors | no for normal use |
| 6 | generated exports and internals | tools only | no manual reading/editing |

## Level 0: One Page Only

Open:

- `USE_THIS_FIRST.md`

Use when:

- you are new;
- the repo feels too large;
- you do not know what to open.

Do not open:

- `kb/`;
- benchmark files;
- generated exports;
- schemas;
- evidence folders;
- legacy folders.

## Level 1: First-Use Files

Open:

- `10_MINUTE_QUICKSTART.md`
- `TOP_10_FILES_FOR_FIRST_USE.md`
- `WHAT_TO_IGNORE_FIRST.md`

Use when:

- you want a small, guided start.

## Level 2: Use-Case Files

Open:

- `USE_CASE_HUB.md`
- one file under `USE_CASES/`

Use when:

- you know your situation: no project, vague idea, design review, learning, reading plan, or claim check.

## Level 3: Context Packs And Prompts

Open:

- `AI_CONTEXT_PACKS.md`
- one file under `context_packs/`
- one file under `hands_on_prompts/`

Use when:

- an AI needs runtime context;
- you want a copy-paste prompt;
- you want one concrete artifact.

## Level 4: Runtime And Framework Reference

Open only when needed:

- `AI_MASTER_RUNTIME_PACK.md`
- `AI_UNCERTAINTY_AND_SOURCE_RULES.md`
- `MASTER_PROBLEM_SOLVER_INDEX.md`
- `MASTER_CAPABILITY_MATRIX.md`
- `MASTER_DOMAIN_MAP.md`

Use when:

- changing AI behavior;
- debugging generic AI answers;
- routing complex design problems.

## Level 5: Governance, Benchmark, Validation, Schemas

Open only when maintaining or auditing:

- `VALIDATION_REPORT.md`
- `SOURCE_GOVERNANCE_AUDIT.md`
- `AI_MASTER_BENCHMARK_*`
- `kb/13_evidence/`
- schema files
- `tools/`

Use when:

- validating;
- auditing;
- scoring benchmark outputs;
- changing entity structures;
- handling evidence governance.

## Level 6: Generated Exports And Internals

Do not manually edit:

- `kb/11_import_export/export/`
- generated validation/export JSON;
- generated graph/search files;
- generated import report.

Use when:

- a tool consumes machine-readable data;
- exports are regenerated by command.

## Default Expansion Rule

If the current level is enough, stop. Do not open a deeper level just because it exists.
