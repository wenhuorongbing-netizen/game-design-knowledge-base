# Output Contract: Prototype Plan

## Artifact Purpose

Define the smallest prototype that can answer one design question.

## Required Sections

- prototype question;
- hypothesis;
- minimum build scope;
- excluded features;
- success signal;
- failure signal;
- timebox;
- next decision.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The plan must be smaller than a production roadmap.

## Source/Confidence Rule

Do not invent project facts or test results.

## Common Failure Modes

- feature roadmap;
- no testable question;
- no stop condition;
- oversized prototype.

## Done Criteria

The user can start a small prototype and know what decision it should inform.
