# Output Contract: Game Feel Audit

## Artifact Purpose

Diagnose responsiveness, floatiness, tightness, input, camera, feedback, and polish issues.

## Required Sections

- feel target;
- current symptom;
- input factors;
- response factors;
- camera/avatar factors;
- feedback factors;
- tuning hypotheses;
- small test.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The audit must separate input, response, feedback, and polish instead of giving generic polish advice.

## Source/Confidence Rule

Do not cite private game feel sources. Do not invent measurements.

## Common Failure Modes

- generic "add juice" advice;
- invented latency;
- no tuning hypothesis;
- no test.

## Done Criteria

The user can run one feel-tuning experiment.
