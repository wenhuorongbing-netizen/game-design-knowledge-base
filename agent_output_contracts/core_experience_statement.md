# Output Contract: Core Experience Statement

## Artifact Purpose

Define what the player repeatedly does, feels, and values.

## Required Sections

- core experience statement;
- player fantasy;
- core verbs;
- emotional promise;
- design pillars;
- pillar tests.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The statement must connect emotion to player action, not only theme.

## Source/Confidence Rule

Treat as draft design scaffolding unless supported by evidence.

## Common Failure Modes

- vague emotion;
- no verbs;
- too many pillars;
- hidden assumptions.

## Done Criteria

The user can judge whether a future feature supports or weakens the core experience.
