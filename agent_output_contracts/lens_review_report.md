# Output Contract: Lens Review Report

## Artifact Purpose

Apply selected design lenses to expose strengths, risks, and next actions.

## Required Sections

- design object reviewed;
- selected lenses and why;
- findings by lens;
- tensions or tradeoffs;
- recommended changes;
- next action.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps.

## Quality Criteria

Each lens must produce a specific observation and actionable implication.

## Source/Confidence Rule

Lens conclusions are draft diagnostics, not verified claims.

## Common Failure Modes

- too many lenses;
- generic findings;
- no tradeoffs;
- no decision.

## Done Criteria

The user knows which design issue to address first.
