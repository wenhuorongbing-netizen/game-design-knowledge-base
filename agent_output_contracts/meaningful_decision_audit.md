# Output Contract: Meaningful Decision Audit

## Artifact Purpose

Diagnose whether player choices create meaningful tradeoffs.

## Required Sections

- decision point;
- player options;
- player information;
- consequences;
- failure mode;
- repair options;
- prototype test.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The audit must distinguish obvious, blind, fake, and meaningful choices.

## Source/Confidence Rule

Use user-supplied mechanics only. Do not claim verified theory without evidence.

## Common Failure Modes

- invented choices;
- no consequence comparison;
- moral framing instead of design analysis;
- no repair.

## Done Criteria

The user can revise the choice or test it.
