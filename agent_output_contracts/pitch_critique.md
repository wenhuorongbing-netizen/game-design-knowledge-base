# Output Contract: Pitch Critique

## Artifact Purpose

Improve a game pitch for clarity, audience fit, hook, credibility, and next action.

## Required Sections

- pitch summary;
- audience fit;
- hook clarity;
- player promise;
- scope and credibility risks;
- missing information;
- revised pitch;
- next action.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps.

## Quality Criteria

The critique must include a concrete rewrite or pitch repair, not only comments.

## Source/Confidence Rule

Do not invent market data, user research, publisher feedback, or benchmark proof.

## Common Failure Modes

- generic encouragement;
- invented audience evidence;
- no rewrite;
- no risk analysis.

## Done Criteria

The user can use the revised pitch or ask for targeted follow-up.
