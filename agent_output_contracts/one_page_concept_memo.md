# Output Contract: One-Page Concept Memo

## Artifact Purpose

Turn a rough game idea into a concise design direction.

## Required Sections

- one-sentence concept;
- target player and player fantasy;
- core experience;
- design pillars;
- key risks;
- next prototype question.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The memo must be specific enough to guide a prototype and short enough to scan quickly.

## Source/Confidence Rule

Default `source_basis`: `unsupported_draft`. Default confidence: weak unless the user supplies real evidence.

## Common Failure Modes

- generic praise;
- invented player data;
- too many pillars;
- no prototype question.

## Done Criteria

The user can decide what to test next.
