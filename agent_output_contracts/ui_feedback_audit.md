# Output Contract: UI Feedback Audit

## Artifact Purpose

Diagnose whether UI feedback helps the player understand state, consequence, and action.

## Required Sections

- player goal;
- state to communicate;
- current feedback;
- missing or noisy signals;
- accessibility concerns;
- repair recommendations;
- usability check.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The audit must identify state and feedback, not only visual taste.

## Source/Confidence Rule

Do not invent user observations.

## Common Failure Modes

- aesthetic critique only;
- no state model;
- no accessibility consideration;
- invented playtest feedback.

## Done Criteria

The user can change one UI feedback state and test it.
