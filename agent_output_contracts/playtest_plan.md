# Output Contract: Playtest Plan

## Artifact Purpose

Define a safe playtest plan before evidence exists.

## Required Sections

- test goal;
- prototype version or scope;
- participant profile;
- tasks;
- observation categories;
- participant quote handling;
- interpretation boundary;
- decision rule;
- next action.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps.

## Quality Criteria

The plan must separate observed facts, quotes, tester interpretation, hypotheses, decisions, and next actions.

## Source/Confidence Rule

Do not invent observations, participants, quotes, or results.

## Common Failure Modes

- fake data;
- leading prompts;
- no observation structure;
- treating one playtest as universal doctrine.

## Done Criteria

The user can run a playtest and record evidence safely.
