# Output Contract: Learning Plan

## Artifact Purpose

Help the user learn game design without requiring an active project.

## Required Sections

- learning goal;
- topic explanation;
- key concepts;
- diagnostic questions;
- exercise;
- artifact to create;
- reflection prompt;
- next topic.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The plan must produce practice, not only reading.

## Source/Confidence Rule

Do not summarize private books or invent citations.

## Common Failure Modes

- lecture only;
- overwhelming reading list;
- no exercise;
- fake source authority.

## Done Criteria

The user can complete one learning exercise and create one artifact.
