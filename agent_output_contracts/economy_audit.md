# Output Contract: Economy Audit

## Artifact Purpose

Diagnose resource flow, inflation, scarcity, sources, sinks, faucets, and drains.

## Required Sections

- resources;
- sources/faucets;
- sinks/drains;
- player incentives;
- inflation or scarcity risks;
- tuning levers;
- test plan.

## Required Labels

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Quality Criteria

The audit must connect economy flow to player behavior and design goals.

## Source/Confidence Rule

Use only user-supplied quantities or mark quantities as assumptions.

## Common Failure Modes

- invented economy rates;
- ignoring sinks;
- no player incentive analysis;
- no validation step.

## Done Criteria

The user can choose a tuning lever and test it.
