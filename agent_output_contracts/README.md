# Agent Output Contracts

Date: 2026-04-30

## Purpose

These contracts define the artifact shapes produced by agent skills.

Every contract requires:

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- next action.

## Universal Failure Conditions

An artifact fails if it invents evidence, quotes, citations, project facts, playtest results, or verified status.
