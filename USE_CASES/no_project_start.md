# Use Case: No Project Yet

Use this if you want the KB to help you learn, think, or generate design practice before you have an active game project.

## What You Provide

- What you want to improve: foundations, choices, systems, game feel, UI, narrative, prototyping, playtesting, or production.
- Optional: your current skill level.

## Copy-Paste Prompt

> Use the Game Design Knowledgebase as an AI Game Design Master runtime. I do not have an active game project yet. Help me make progress without inventing project facts.
>
> Create a short learning-and-practice plan for this topic: [topic].
>
> Include: what I should understand, 3 expert questions, one small exercise, one draft artifact I can create, relevant lenses/workflows, safe reading-note prompts, `source_basis`, confidence, evidence gaps, and one next action.

## Expected Output

| Section | What you should get |
|---|---|
| learning target | The specific design capability to practice. |
| expert questions | Questions that teach design judgment. |
| exercise | A small task you can do without a project. |
| draft artifact | Example: decision matrix, concept memo, rule table, or system sketch. |
| reading-note prompt | What you can answer after reading manually. |
| safety labels | No fake project evidence or verified claims. |

## Safety Boundary

The AI can help you practice. It must not invent a project, player feedback, market result, playtest, or source-backed claim.
