# Use Case: Learn Game Design

Use this when you want the AI to teach a concept or help you choose what to learn next.

## What You Provide

- A topic, concept, or design problem.
- Optional: beginner, intermediate, or advanced level.

## Copy-Paste Prompt

> Use the Game Design Knowledgebase as an AI Game Design Master runtime. Teach me this game design topic as a draft/source-governed lesson, not as verified book doctrine.
>
> Topic: [topic]
>
> Level: [beginner/intermediate/advanced]
>
> Include: simple explanation, why it matters, when to use it, when not to use it, 3 diagnostic questions, one exercise, related capability, related workflow, what evidence would be needed for stronger claims, `source_basis`, confidence, and one next topic.

## Expected Output

| Section | What you should get |
|---|---|
| explanation | Clear working definition. |
| why it matters | Design relevance. |
| use / do not use | Practical boundaries. |
| questions | Socratic prompts. |
| exercise | A small practice task. |
| next topic | Logical follow-up. |
| safety labels | Draft/confidence/evidence status. |

## Safety Boundary

The AI must not pretend it is summarizing a private chapter or quoting a book. It should say what user notes or legal evidence would be required for source-backed teaching.
