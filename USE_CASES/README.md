# Hands-On Use Cases

Pick one use case. You do not need to understand the whole repository first.

## Fast Index

| Situation | Use case | Output |
|---|---|---|
| I have a rough game idea. | [vague_game_idea.md](vague_game_idea.md) | one-page concept memo |
| I want critique on a concept. | [design_review.md](design_review.md) | design review with lenses and next action |
| I do not have a project yet. | [no_project_start.md](no_project_start.md) | learning route or idea-generation route |
| I want to learn game design. | [learn_game_design.md](learn_game_design.md) | mini lesson, exercise, and next topic |

| I want to check a claim or citation. | [source_safety_check.md](source_safety_check.md) | evidence gap report |

## How To Use A Use Case

1. Open the use-case page.
2. Copy the prompt.
3. Replace bracketed fields.
4. Tell the AI to use [AI_CONTEXT_MINIMAL.md](../AI_CONTEXT_MINIMAL.md).
5. Expect a draft answer unless real evidence exists.

## Default Trust Rule

Most first-use outputs are design scaffolds:

- `source_basis`: `unsupported_draft`
- confidence: `weak`
- verified claims: none
- evidence_refs: none unless already supplied
