# Use Case: Vague Game Idea

Use this when you have only a sentence or two and want the AI to help shape it.

## What You Provide

- One or two sentences describing the idea.
- Optional: target platform, genre, intended player feeling, or constraint.

## Copy-Paste Prompt

> Use the Game Design Knowledgebase as an AI Game Design Master runtime. Treat the KB as draft/source-governed scaffolding unless evidence exists. Review my rough idea and produce a one-page concept memo.
>
> Include: inferred player fantasy, core experience, likely repeated action, 3 design pillars, 3 risks, 3 diagnostic questions, one suggested workflow, assumptions, `source_basis`, confidence, evidence gaps, and one next action.
>
> My idea: [write your idea]

## Expected Output

| Section | What you should get |
|---|---|
| concept summary | What the idea seems to be. |
| core experience | What the player should feel and do repeatedly. |
| design pillars | 3 principles to guide future choices. |
| likely loop | A draft action-feedback-repeat loop. |
| diagnostic questions | 3 high-value questions. |
| risks | Scope, clarity, novelty, or production risks. |
| workflow | Usually Game Idea to One-Page Concept or Core Experience Definition. |
| next action | One small action, not a huge plan. |

## Safety Boundary

The AI must not claim player demand, market fit, verified book theory, or playtest evidence. This is a draft concept-shaping artifact.
