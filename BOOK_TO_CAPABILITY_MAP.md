# Book To Capability Map

Date: 2026-04-29

## Purpose

This file maps registered game design works to AI Game Design Master capabilities.

The mapping is source-safe. It uses only existing work registry metadata, source-risk records, dossier shells, taxonomy routing, and the master capability matrix. It does not summarize chapters, quote books, parse private source bodies, or create verified claims.

## Governance Rule

Every mapping below is a routing hypothesis for the AI master framework. It helps the AI know which works are relevant to which capability, but it does not prove what any work says internally.

High-risk uploaded works remain metadata-only. Prompt-referenced works remain reference-list records until official metadata, legal sidecars, or user notes are supplied.
