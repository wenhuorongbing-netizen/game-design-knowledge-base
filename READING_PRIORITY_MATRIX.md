## Suggested Reading Order For The Current User State

The user has many books but no reading notes and no active project. The best path is therefore breadth-first, not project-first.

1. Read enough of The Art of Game Design to create user notes about lens-based questioning.
2. Read enough of Game Design Workshop to create user notes about process, prototyping, and playtesting.
3. Read enough of Game Mechanics or Rules of Play to create user notes about formal mechanics and decisions.
4. Read enough of A Theory of Fun to create user notes about player experience and learning.
5. Read enough of Advanced Game Design or Characteristics of Games to create user notes about systems and economy.
6. Read enough of Level Up! to create user notes about practical production, UI, level, and pitch artifacts.
