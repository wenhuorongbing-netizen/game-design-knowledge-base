# Generated Export Files

This folder is generated by the authoritative importer.

- Status: generated
- Users: importers, search consumers, graph consumers, maintainers
- Edit: no manual edits
- Updated by: `npm run kb:export` or `npm run kb:validate`

Expected generated files:

- `all_entities.json`
- `all_relationships.json`
- `search_index.json`
- `graph_nodes.json`
- `graph_edges.json`
- `validation_issues.json`

If an export is wrong, edit the canonical source files or importer, then regenerate.
