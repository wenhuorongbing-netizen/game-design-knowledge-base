# Forum Thread Templates

## Thread Types

### Source Clarification Thread

- What does the source explicitly support?
- What is still inference?

### Design Comparison Thread

- Which two works or cards are being compared?
- What is the comparison axis?

### Project Application Thread

- What project problem is being solved?
- Which KB objects were applied?
- What was actually tested?

### Playtest Evidence Thread

- What was observed?
- What changed?
- What remains uncertain?
