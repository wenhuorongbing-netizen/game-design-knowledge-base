# Discussion Quality Rules

## Every Discussion Should Distinguish

- source statement
- user interpretation
- AI hypothesis
- project application
- playtest evidence

## Bad Discussion Smells

- “the book says” with no source basis
- quoting suspicious files
- turning metadata into doctrine
- mixing project opinion with general truth

## Good Discussion Traits

- cites source IDs
- cites source basis
- cites confidence
- identifies uncertainty clearly
