# Masterclass Curriculum

Prompt 7 turns the KB into a structured learning system. Lessons are original teaching scaffolds and production practice units, not book summaries. All generated lessons start as `source_basis: unsupported_draft`, `confidence: unsupported_draft`, and `status: draft`.

## Governance Rule

No copyrighted source body text was used. Related dossiers are reading targets and metadata anchors only. Any lesson can be promoted only after user notes, legal source evidence, project overlays, or playtest logs support it.

## Counts

- tracks: 10
- lessons: 84
- levels: beginner, intermediate, advanced, professional

## Learning Paths

- Beginner path: Track 1, Track 2, selected Track 3 basics.
- Intermediate path: Track 3, Track 4, Track 5, Track 6, Track 7.
- Advanced path: Track 4 advanced lessons, Track 7 integration, Track 10 audits.
- Project-team path: Track 8, Track 9, Track 10, with weekly project overlays and playtest logs.
