# Project Application Guide

## Rule

General knowledge and project application must stay separate.

## Overlay Contents

A project overlay may contain:

- selected cards
- selected lenses
- linked workflow outputs
- project-specific assumptions
- design decisions
- playtest logs
- playtest outcomes
- implementation tradeoffs

## Forbidden Shortcut

Do not write project conclusions back into the global KB without re-validation.

## Required Boundary

Every overlay must distinguish:

- reusable KB concept;
- project-specific assumption;
- observed playtest result;
- design decision;
- AI hypothesis;
- unsupported draft note.

Use `source_basis`, `confidence`, and `evidence_refs` exactly as in other KB entities.
