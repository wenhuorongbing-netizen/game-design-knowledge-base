# Evidence-Weighted Designer Path

Date: 2026-04-28

Use this path when you want to solve a design problem while keeping evidence status visible.

Current rule: start with workflows for action, lenses for diagnosis, cards for vocabulary, and evidence reports for trust level.

## Evidence Status Legend

| Label | Meaning |
|---|---|
| draft only | Useful workflow or concept scaffold; not verified. |
| evidence gap open | Missing notes, project evidence, playtest evidence, or EvidenceRefs. |
| metadata only | Bibliographic or metadata-safe basis only. |
| project-local | Can support one project only after a real ProjectOverlay exists. |
| playtest-local | Can support one playtest context only after a real PlaytestLog exists. |
| verified | Requires legal EvidenceRefs and promotion review; current count is 0. |
