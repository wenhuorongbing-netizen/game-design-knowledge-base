# Quality

This folder contains release checks, legal audits, hallucination audits, coverage matrices, gap backlogs, and release reports.

- Status: mixed canonical and generated
- Users: QA reviewers, maintainers, source auditors
- Edit: human-authored reports carefully; generated summaries no
- Updated by: `npm run kb:coverage`, `npm run kb:audit`, and manual review reports

Quality reports distinguish draft KB acceptance from verified source-backed masterclass acceptance.
