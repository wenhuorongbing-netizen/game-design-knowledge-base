# UI / Feedback Exercise 07: rewrite a design assumption

## Purpose

Practice turning ui / feedback knowledge into a concrete design artifact without relying on unsupported source claims.

## Materials

- timer
- blank worksheet
- current game idea or prototype note
- linked cards and lenses

## Setup

Choose one concrete artifact. State the intended player experience and current evidence before starting.

## Steps

- Write the current assumption in one sentence.
- Use the linked cards as vocabulary anchors.
- Run the linked lenses and record three findings.
- Create the expected output artifact.
- Mark missing evidence and one next experiment.

## Constraints

- Do not use book body text.
- Do not cite a card or lens as verified unless it has evidence.
- Keep the output reviewable in one page or one board.

## Expected Output

UI / Feedback one-page exercise output with assumptions, evidence gaps, and next action.
