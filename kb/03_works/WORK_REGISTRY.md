# Work Registry

## Purpose

This registry tracks `GameDesignWork` objects separately from concrete source files.

A work may have:

- zero registered source files
- one high-risk source file
- multiple duplicate source files
- only a user prompt reference
- later official metadata or legal sidecars

Prompt 2 registry entries are navigation and inventory records, not book summaries.
