# Designer Workflows

Use this file when you are working on a game and need a concrete next action. Start with the workflow pack, then use the lenses to diagnose the artifact.

## I Have A Game Idea

- Workflow: [Game Idea to One-Page Concept](08_workflows/packs/workflow_game-idea-to-one-page-concept.md)
- Lenses: [core experience](06_lenses/cards/lens_project-direction_core-experience.md), [audience](06_lenses/cards/lens_project-direction_audience.md), [player fantasy](06_lenses/cards/lens_project-direction_player-fantasy.md), [scope](06_lenses/cards/lens_project-direction_scope.md)
- Output: one-page concept with audience, fantasy, experience target, scope, assumptions, and next prototype question.

## My Core Loop Is Weak

- Workflow: [Core Loop Design](08_workflows/packs/workflow_core-loop-design.md)
- Lenses: [core loop](06_lenses/cards/lens_mechanics-and-rules_core-loop.md), [parts loops whole](06_lenses/cards/lens_systems-and-economy_parts-loops-whole.md), [feedback loops](06_lenses/cards/lens_systems-and-economy_feedback-loops.md)
- Output: core loop map with actions, feedback, rewards, friction, repetition, and risks.

## My Choices Do Not Feel Meaningful

- Workflow: [Meaningful Decision Audit](08_workflows/packs/workflow_meaningful-decision-audit.md)
- Lenses: [meaningful decisions](06_lenses/cards/lens_mechanics-and-rules_meaningful-decisions.md), [tradeoffs](06_lenses/cards/lens_mechanics-and-rules_tradeoffs.md), [dilemma quality](06_lenses/cards/lens_mechanics-and-rules_dilemma-quality.md)
- Output: decision audit table showing options, consequences, information, reversibility, risk, reward, and fake-choice warnings.

## My Game Feels Floaty

- Workflow: [Game Feel Prototype](08_workflows/packs/workflow_game-feel-prototype.md)
- Lenses: [input responsiveness](06_lenses/cards/lens_game-feel_input-responsiveness.md), [response clarity](06_lenses/cards/lens_game-feel_response-clarity.md), [tight versus floaty](06_lenses/cards/lens_game-feel_tight-versus-floaty.md), [juiciness versus noise](06_lenses/cards/lens_game-feel_juiciness-versus-noise.md)
- Output: tuning experiment plan with input, response, context, polish, and playtest checks.

## My Economy Is Broken

- Workflow: [Economy and Balance](08_workflows/packs/workflow_economy-and-balance.md)
- Lenses: [source sink balance](06_lenses/cards/lens_systems-and-economy_source-sink-balance.md), [economy readability](06_lenses/cards/lens_systems-and-economy_economy-readability.md), [balance resilience](06_lenses/cards/lens_systems-and-economy_balance-resilience.md), [runaway loops](06_lenses/cards/lens_systems-and-economy_runaway-loops.md)
- Output: economy map with sources, sinks, rates, caps, inflation risks, and telemetry needs.

## My UI Feedback Is Unclear

- Workflow: [UI Feedback](08_workflows/packs/workflow_ui-feedback.md)
- Lenses: [information priority](06_lenses/cards/lens_ui-ux-feedback_information-priority.md), [feedback immediacy](06_lenses/cards/lens_ui-ux-feedback_feedback-immediacy.md), [mode clarity](06_lenses/cards/lens_ui-ux-feedback_mode-clarity.md), [accessibility](06_lenses/cards/lens_ui-ux-feedback_accessibility.md)
- Output: UI feedback audit with priority, visibility, timing, input mapping, error recovery, and accessibility risks.

## My Narrative Does Not Support Mechanics

- Workflow: [Narrative-Mechanic Alignment](08_workflows/packs/workflow_narrative-mechanic-alignment.md)
- Lenses: [story function](06_lenses/cards/lens_narrative-world-character_story-function.md), [player role](06_lenses/cards/lens_narrative-world-character_player-role.md), [narrative agency](06_lenses/cards/lens_narrative-world-character_narrative-agency.md), [thematic resonance](06_lenses/cards/lens_narrative-world-character_thematic-resonance.md)
- Output: alignment matrix mapping player actions, story claims, world rules, character functions, and contradictions.

## I Need To Playtest

- Workflow: [Playtest Plan](08_workflows/packs/workflow_playtest-plan.md)
- Lenses: [prototype question](06_lenses/cards/lens_prototype-and-playtest_prototype-question.md), [playtest signal](06_lenses/cards/lens_prototype-and-playtest_playtest-signal.md), [observation quality](06_lenses/cards/lens_prototype-and-playtest_observation-quality.md), [test bias](06_lenses/cards/lens_prototype-and-playtest_test-bias.md)
- Output: playtest plan with research question, participant profile, tasks, observation rubric, interview questions, and iteration criteria.

## I Need To Prepare For Release

- Workflow: [Release Readiness Risk Audit](08_workflows/packs/workflow_release-readiness-risk-audit.md)
- Lenses: [launch readiness](06_lenses/cards/lens_production-release-community_launch-readiness.md), [documentation](06_lenses/cards/lens_production-release-community_documentation.md), [community health](06_lenses/cards/lens_production-release-community_community-health.md), [responsibility](06_lenses/cards/lens_production-release-community_responsibility.md)
- Output: release risk register with blocker list, known unknowns, player-facing risks, owner, and next review date.
