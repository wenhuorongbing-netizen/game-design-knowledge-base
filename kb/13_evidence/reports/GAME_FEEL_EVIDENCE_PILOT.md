# Game Feel Evidence Pilot

Generated: 2026-04-27

## Scope

This is a limited Evidence Intake Phase 1 pilot for the `game_feel` domain. It builds evidence slots and evidence gaps only. It does not parse high-risk source body text, summarize private PDFs or EPUBs, extract quotes, create verified claims, or promote claims.

## Source Boundary

Two uploaded variants exist, both high-risk mirror-marked and quarantined metadata-only. Existing Game Feel source documents remain metadata-only; do not use uploaded body text.

Allowed basis for this pilot:

- existing metadata
- user-provided manual notes
- user manual quotes supplied by the user and kept short
- official metadata
- lawful open sources if already allowed
- draft placeholders with evidence gaps
