# User Manual Note Example Stub

This file is an example stub and is ignored by the importer.

It shows the intended shape without adding a real note:

- `note_id`: stable note ID
- `work_id`: existing GameDesignWork ID
- `source_document_id`: optional SourceDocument ID
- `note_type`: one controlled note type
- `user_summary`: user-authored summary only
- `user_interpretation`: user interpretation only
- `confidence`: `user_interpretation`
- `status`: `draft`, `review_needed`, `accepted_user_note`, or `rejected`

Do not paste book text into this file.
