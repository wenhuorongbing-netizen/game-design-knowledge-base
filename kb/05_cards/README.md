# Cards

This folder contains source-governed knowledge cards.

- Status: canonical
- Users: learners, designers, researchers, maintainers
- Edit: yes, carefully
- Updated by: human card edits; validate with `npm run kb:validate`

Card folders include concept, framework, application, checklist, prompt, quote, comparison, exercise, anti-pattern, and case-study card areas.

Every real card must preserve `source_basis`, `confidence`, `status`, and evidence fields.

Placeholder-only card folders are documented in [PLACEHOLDER_CARD_FOLDERS.md](PLACEHOLDER_CARD_FOLDERS.md) instead of using README files inside entity scan folders.
