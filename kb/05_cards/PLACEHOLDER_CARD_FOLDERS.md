# Placeholder Card Folders

These card types are implemented in the universal card schema and template, but they currently do not contain generated entity cards.

This file preserves the former README placeholder notes outside entity scan folders so validation no longer needs README-specific accepted exceptions.

| Folder | Card Type | Current Status | Reason |
|---|---|---|---|
| `quote_cards/` | quote cards | placeholder folder | Safe evidence or user/manual legal quotes are required before quote cards should contain substantive content. |
| `comparison_cards/` | comparison cards | placeholder folder | Safe evidence or project cases are required before comparison cards should contain substantive content. |
| `exercise_cards/` | exercise cards | placeholder folder | Exercises currently live under `kb/08_workflows/exercises/`; no separate Prompt 5 exercise-card entities were created. |
| `anti_pattern_cards/` | anti-pattern cards | placeholder folder | Safe evidence or project cases are required before anti-pattern cards should contain substantive content. |
| `case_study_cards/` | case-study cards | placeholder folder | Case studies require lawful source material or project evidence before substantive content should be created. |

Do not create substantive cards in these folders without `source_basis`, `confidence`, `status`, and evidence fields.
