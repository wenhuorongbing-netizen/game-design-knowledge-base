# Codex Task Recipes

Date: 2026-04-30

## Purpose

These recipes show how a user can ask Codex to use this repository as a Game Design Skill Pack.

They are not benchmark prompts and not evidence.

## Runtime Rule

Codex should start at `AGENT_START.md`, route through `AGENT_ROUTER.md`, load one skill, and produce one artifact.
