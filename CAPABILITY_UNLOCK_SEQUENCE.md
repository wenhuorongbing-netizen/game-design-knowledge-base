# Capability Unlock Sequence

Date: 2026-04-29

## Purpose

This file defines what the user and AI Master Framework can do after each capability is unlocked.

## Unlock Rule

A capability is considered unlocked when the user can:

- explain the capability in one sentence;
- run at least one related workflow;
- complete at least one related exercise;
- create at least one user note;
- use one AI prompt safely;
- produce one artifact with assumptions and source/confidence status.

## Master Synthesis

Master synthesis begins only after the user can combine:

- core experience;
- formal structure;
- meaningful decisions;
- systems/economy;
- feedback/UI;
- prototype/playtest;
- production and responsibility.

The AI can then run multi-lens design reviews while still marking evidence limits.
