# Start For Maintainers

Date: 2026-04-30

Maintainers should start with:

- `KB_REBUILD_INSTRUCTION.md`
- `QUALITY_GATE_PLAN.md`
- `VALIDATION_REPORT.md`
- `SOURCE_GOVERNANCE_AUDIT.md`
- `DOCUMENTATION_GOVERNANCE_SYSTEM.md`
- `DEFINITION_OF_DONE.md`

Required commands:

- `npm run kb:export`
- `npm run kb:validate`
- `npm run kb:audit`
- `npm run kb:coverage`

Do not manually edit generated exports.
