# No-Project AI Practice Sessions

Date: 2026-04-30

## Purpose

These sessions show how to use AI as a learning coach without inventing projects, playtests, source evidence, or benchmark outputs.

## Session Format

Each session should take 20 to 40 minutes:

1. Choose one capability.
2. Load the smallest context pack.
3. Paste one prompt.
4. Produce one artifact.
5. Ask AI to self-check assumptions, source_basis, confidence, and evidence gaps.
6. Write one short reflection note.

## Session 1 - Concept Sprint

| Field | Content |
|---|---|
| context pack | CP02_game_idea_review |
| prompt | Review five one-sentence concepts and select the one with the clearest player action. |
| artifact | concept selection memo |
| reflection note | why the selected concept is clearer |
| do not overclaim | no concept is proven viable |
