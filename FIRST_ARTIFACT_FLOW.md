# First Artifact Flow

Date: 2026-04-30

## Goal

Create one useful artifact before browsing the repository.

## Flow

### Step 1: Pick The Artifact

Open [FIRST_ARTIFACT_MENU.md](FIRST_ARTIFACT_MENU.md).

Choose one artifact only.

### Step 2: Load One Context Pack

Open the context pack listed for that artifact.

Do not load the whole repository.

### Step 3: Copy One Prompt

Open the listed prompt file.

Copy only the "Copy-Paste Prompt" section.

### Step 4: Paste One Input

Replace bracketed fields such as `[paste your idea]`.

Write `unknown` if you do not know an optional field.

### Step 5: Ask For One Artifact

The AI should produce the named artifact first.

It may ask at most 3 high-value questions if blocked.

### Step 6: Check The Trust Labels

Before using the answer, check:

- assumptions;
- source_basis;
- confidence;
- evidence gaps;
- next action.

### Step 7: Decide The Next Action

Choose one:

- revise the artifact;
- ask for a smaller version;
- run a specific audit;
- make a prototype plan;
- create a learning exercise;
- check a claim for source safety.

## Do Not Do This First

Do not start by opening:

- benchmark reports;
- validation internals;
- source governance audits;
- evidence sidecars;
- schemas;
- generated exports.

## Success Condition

You are done when you have one artifact that is useful enough to act on and does not pretend to be verified evidence.
