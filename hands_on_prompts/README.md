# Hands-On Prompts

This folder contains copy-paste prompts for actual user use. These prompts are shorter and more practical than the full master prompt templates.

## Use This Folder When

- you have a vague idea;
- you want a design review;
- you want learning help;
- you need a prototype or playtest plan;
- you want to check whether a claim is supported;
- you want the AI to produce a concrete design artifact safely.

## Safety Rule

These prompts are for draft/source-governed use. They do not authorize the AI to summarize private books, invent evidence, cite books without EvidenceRefs, or mark claims verified.
