# Agent Smoke Tests

Date: 2026-04-30

## Purpose

Smoke tests verify that common user tasks can route to skills and artifacts.

## Smoke Test Set

| Test | User task | Expected skill | Expected artifact | Pass criteria |
|---|---|---|---|---|
| ST-001 | "Review my game idea" | game_idea_review | one-page concept memo | skill selected, assumptions labeled |
| ST-002 | "Define the core experience" | core_experience_definition | core experience statement | core verbs and pillars included |
| ST-003 | "Run a lens review" | lens_review | lens review report | 3 to 5 lenses selected |
| ST-004 | "My choices feel fake" | meaningful_decision_audit | decision audit | options/info/consequences mapped |
| ST-005 | "My economy inflates" | systems_economy_audit | economy audit | sources and sinks listed |
| ST-006 | "My game feels floaty" | game_feel_feedback_audit | game feel audit | input/response/feedback separated |
| ST-007 | "Make a prototype plan" | prototype_plan | prototype plan | one testable question |
| ST-008 | "Make a playtest plan" | playtest_plan | playtest plan | no invented results |
| ST-009 | "Teach me game design" | learning_coach | mini lesson or learning plan | exercise included |
| ST-010 | "Is this claim verified?" | claim_safety_check | claim safety report | no fake EvidenceRef |

## Current Status

Prepared. These smoke tests are not scored benchmark results.
