# Prototyping Pack Ready To Run

Cross-phase bundle for validating a concept quickly through loop design, prototype implementation, and playtest framing.

## Use This When

Use this when the project is still proving whether the core idea is worth scaling up.

## Prepare Before You Start

- [ ] Core fantasy and target player
- [ ] Single mechanic or loop hypothesis
- [ ] Prototype platform and implementation constraints
- [ ] Playtest questions you need answered

## Run Order

1. [立项与方向 Prompt 模板](../cards/prompt-initiation-direction.md)
    - Goal: 把模糊项目概念收束成方向判断、目标市场、平台适配和 MVP 裁剪结论。
    - Type: Prompt Template
2. [核心玩法与系统设计 Prompt 模板](../cards/prompt-core-gameplay-systems.md)
    - Goal: 把核心 fantasy 压成核心循环、机制、状态变化和可验证原型。
    - Type: Prompt Template
3. [核心循环设计 Prompt 模板](../cards/prompt-core-loop-design.md)
    - Goal: 把玩家的动机、动作、回报和下一轮驱动力压成清晰闭环。
    - Type: Prompt Template
4. [原型实现 Prompt 模板](../cards/prompt-prototype-implementation.md)
    - Goal: 把一个设计命题压成最小实现范围、技术切片和验证顺序。
    - Type: Prompt Template
5. [单机制原型 Checklist](../cards/checklist-single-mechanic-prototype-design.md)
    - Goal: 检查一个原型是否真的只在验证一个机制，而不是偷带了半个游戏。
    - Type: Checklist
6. [新手引导设计 Checklist](../cards/checklist-onboarding-design.md)
    - Goal: 检查前 5-10 分钟是否真的教会了玩家，而不是只展示了功能。
    - Type: Checklist
7. [测试、验收与审计 Prompt 模板](../cards/prompt-testing-acceptance-audit.md)
    - Goal: 把当前版本转成清晰的验收标准、试玩问题、回归项和 stop/go 结论。
    - Type: Prompt Template

## Working Rule

Move in order. Treat each prompt card as a draft-producing step and each checklist as a decision gate before advancing.
