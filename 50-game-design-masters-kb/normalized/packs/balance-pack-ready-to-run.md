# Balance Pack Ready To Run

Cross-phase bundle for economy architecture, combat numbers, reward logic, and balance review loops.

## Use This When

Use this when the game has enough systems to show inflation, dead rewards, or unclear progression pressure.

## Prepare Before You Start

- [ ] Key currencies and resource flows
- [ ] Combat stats and progression targets
- [ ] Reward tables, drop logic, or progression pacing
- [ ] Current balance pain points or telemetry symptoms

## Run Order

1. [数值与经济设计 Prompt 模板](../cards/prompt-numbers-economy.md)
    - Goal: 把资源、货币、成长、奖励与风险映射成可平衡的数值框架。
    - Type: Prompt Template
2. [经济系统设计 Prompt 模板](../cards/prompt-economy-system-design.md)
    - Goal: 把资源和货币系统整理成层级、流向、稀缺关系与调参点。
    - Type: Prompt Template
3. [货币系统设计 Prompt 模板](../cards/prompt-currency-system-design.md)
    - Goal: 把多个货币和稀缺资源整理成层级清晰、目标明确的货币结构。
    - Type: Prompt Template
4. [战斗数值平衡 Prompt 模板](../cards/prompt-combat-balance.md)
    - Goal: 把战斗系统整理成 TTK、输出窗口、生存压力和风险回报的平衡结构。
    - Type: Prompt Template
5. [成长曲线设计 Checklist](../cards/checklist-growth-curve-design.md)
    - Goal: 检查成长是否真的带来新理解，而不是只是数字更大。
    - Type: Checklist
6. [掉落与奖励设计 Checklist](../cards/checklist-drop-reward-design.md)
    - Goal: 检查奖励是否真的驱动玩家决策，而不是只做表面兴奋剂。
    - Type: Checklist
7. [资源产出消耗设计 Checklist](../cards/checklist-resource-production-consumption.md)
    - Goal: 检查资源流是否真的形成节奏与选择，而不是只形成等待与堆积。
    - Type: Checklist

## Working Rule

Move in order. Treat each prompt card as a draft-producing step and each checklist as a decision gate before advancing.
