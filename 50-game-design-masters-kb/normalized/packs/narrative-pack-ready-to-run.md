# Narrative Pack Ready To Run

Cross-phase bundle for worldbuilding, dialogue, quest text, and narrative structure reviews.

## Use This When

Use this when story content exists but lacks a clear structure, tone, or production-ready text workflow.

## Prepare Before You Start

- [ ] World premise and role of the player
- [ ] Main cast, faction, or conflict outline
- [ ] Narrative format and delivery constraints
- [ ] Samples of current dialogue or quest text

## Run Order

1. [世界观设定 Prompt 模板](../cards/prompt-worldbuilding.md)
    - Goal: 把世界观从背景设定压成与玩法、身份、资源和冲突真正相关的设计框架。
    - Type: Prompt Template
2. [对话写作 Prompt 模板](../cards/prompt-dialogue-writing.md)
    - Goal: 把角色对话压成身份、关系、信息效率和可玩性兼顾的文本方案。
    - Type: Prompt Template
3. [叙事结构评审 Checklist](../cards/checklist-narrative-structure-review.md)
    - Goal: 检查主线、支线和系统事件是否形成了清楚的叙事推进结构，而不是内容堆砌。
    - Type: Checklist
4. [任务文本设计 Checklist](../cards/checklist-quest-text-design.md)
    - Goal: 检查任务文本是否清楚、可执行、符合角色与世界规则。
    - Type: Checklist

## Working Rule

Move in order. Treat each prompt card as a draft-producing step and each checklist as a decision gate before advancing.
