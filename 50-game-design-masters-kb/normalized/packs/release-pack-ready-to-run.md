# Release Pack Ready To Run

Cross-phase bundle for preparing a playable release candidate, external messaging, and post-launch planning.

## Use This When

Use this when a project is moving from internal development into public testing, store presence, or release preparation.

## Prepare Before You Start

- [ ] Target release window and platform set
- [ ] Current build quality and known defects
- [ ] Store-facing fantasy, hook, and audience
- [ ] Retention goals and live-ops expectations

## Run Order

1. [商店页文案 Prompt 模板](../cards/prompt-store-page-copy.md)
    - Goal: 把项目卖点压成商店页 headline、短描述、长描述和 feature bullets。
    - Type: Prompt Template
2. [发布前检查 Checklist](../cards/checklist-pre-release-check.md)
    - Goal: 检查项目在对外试玩、上架或发版本前是否已经满足最基本的发布条件。
    - Type: Checklist
3. [版本验收 Checklist](../cards/checklist-build-acceptance.md)
    - Goal: 检查当前 build 是否达到可提交、可试玩、可继续迭代的最低门槛。
    - Type: Checklist
4. [留存优化 Prompt 模板](../cards/prompt-retention-optimization.md)
    - Goal: 把留存问题压成具体的流失节点、驱动力缺口和可实验优化点。
    - Type: Prompt Template
5. [更新路线图 Checklist](../cards/checklist-update-roadmap.md)
    - Goal: 检查 roadmap 是否围绕玩家价值和阶段判断，而不是杂乱功能愿望单。
    - Type: Checklist
6. [平台适配判断 Prompt 模板](../cards/prompt-platform-fit-evaluation.md)
    - Goal: 把项目与平台之间的控制、节奏、会话长度和商业预期冲突压成明确判断。
    - Type: Prompt Template

## Working Rule

Move in order. Treat each prompt card as a draft-producing step and each checklist as a decision gate before advancing.
