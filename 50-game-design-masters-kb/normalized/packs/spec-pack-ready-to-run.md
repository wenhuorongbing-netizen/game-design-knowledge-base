# Spec Pack Ready To Run

Cross-phase bundle for turning a game idea into a structured design and implementation spec.

## Use This When

Use this when you need to align direction, lock the gameplay frame, and turn it into an executable implementation plan.

## Prepare Before You Start

- [ ] One-sentence pitch and project identity
- [ ] Target players, market, and reference titles
- [ ] Core loop assumptions and economy goals
- [ ] Platform, scope, and team constraints

## Run Order

1. [立项与方向 Prompt 模板](../cards/prompt-initiation-direction.md)
    - Goal: 把模糊项目概念收束成方向判断、目标市场、平台适配和 MVP 裁剪结论。
    - Type: Prompt Template
2. [核心循环设计 Prompt 模板](../cards/prompt-core-loop-design.md)
    - Goal: 把玩家的动机、动作、回报和下一轮驱动力压成清晰闭环。
    - Type: Prompt Template
3. [经济系统设计 Prompt 模板](../cards/prompt-economy-system-design.md)
    - Goal: 把资源和货币系统整理成层级、流向、稀缺关系与调参点。
    - Type: Prompt Template
4. [开发实现 Prompt 模板](../cards/prompt-development-implementation.md)
    - Goal: 把设计意图落成技术方案、模块边界、状态流和里程碑。
    - Type: Prompt Template
5. [HUD / UI 结构设计 Prompt 模板](../cards/prompt-hud-ui-structure-design.md)
    - Goal: 把 UI 面板、常驻信息和上下文反馈压成一套可读的结构方案。
    - Type: Prompt Template
6. [MVP 范围裁剪 Checklist](../cards/checklist-mvp-scope-cut.md)
    - Goal: 检查一个项目的首版范围是否已经被压到可验证、可交付、可止损。
    - Type: Checklist
7. [开发实现审查 Checklist](../cards/checklist-development-implementation.md)
    - Goal: 检查技术方案是否真正支撑验证、协作和后续扩展。
    - Type: Checklist

## Working Rule

Move in order. Treat each prompt card as a draft-producing step and each checklist as a decision gate before advancing.
