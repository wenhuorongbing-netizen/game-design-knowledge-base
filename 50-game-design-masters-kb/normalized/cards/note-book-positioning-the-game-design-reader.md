# The Game Design Reader: A Rules of Play Anthology：知识定位

## 这本书最适合解决什么

最适合在你需要扩大理论边界、统一设计讨论语言、或建立阅读型设计评审时介入，而不是拿来直接替代具体的实现方法书。

## 主要关注

- 关注领域：游戏定义与批评 / 规则与系统 / 游戏空间与叙事 / 游戏文化与社群 / 设计研究方法
- 主要用途：高层设计审查 / 理论补课 / 阅读小组共读 / 跨书目比较
- 推荐读法：按主题抽读 / 按作者与论文反查 / 作为理论索引长期常备
- 价值类型：案例库 / 批评视角 / 术语背景 / 经典文本入口
- 适用阶段：立项前研究 / 方向校准 / 设计复盘 / 知识库扩写
