# Advanced Game Design: A Systems Approach：知识定位

## 这本书最适合解决什么

最适合处理中层系统结构、玩法之间的依赖关系以及“为什么整体体验不成立”这类跨系统问题。

## 主要关注

- 关注领域：系统思维 / 循环关系 / 体验目标映射 / 复杂性管理
- 主要用途：中层系统梳理 / 循环关系审查 / 体系化设计复盘
- 推荐读法：按概念通读 / 与 MDA 和 Game Mechanics 对照 / 围绕具体项目结构反查
- 价值类型：中层方法论 / 结构桥梁 / 系统语言
- 适用阶段：方向细化 / 系统方案评审 / 跨系统复盘
