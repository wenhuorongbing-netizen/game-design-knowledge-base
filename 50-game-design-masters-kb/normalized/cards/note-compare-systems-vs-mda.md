# Advanced Game Design: A Systems Approach vs MDA: A Formal Approach to Game Design and Game Research

> Use MDA as the compact alignment frame, then use A Systems Approach to reason through how the interacting loops actually create or break that alignment.

## Advanced Game Design: A Systems Approach 更强在什么地方

- 中层系统梳理
- 循环关系审查
- 体系化设计复盘
- 中层方法论
- Use when: You need a concise way to align mechanics, dynamics, and aesthetics across the team.

## MDA: A Formal Approach to Game Design and Game Research 更强在什么地方

- Use when: You need to unpack how multiple loops and dependencies interact after that top-line alignment is clear.

## 如何一起使用
