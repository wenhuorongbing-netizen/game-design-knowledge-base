# Game Design Workshop：知识定位

## 这本书最适合解决什么

最适合在你已经有游戏方向、但需要把想法变成可测试原型、可复盘文档和可迭代流程时介入。

## 主要关注

- 关注领域：playcentric process / 原型方法 / 试玩组织 / 玩家体验目标 / 设计文档表达
- 主要用途：原型推进 / 试玩流程建设 / 设计文档规范化 / 团队训练
- 推荐读法：按流程顺序通读 / 原型阶段对照使用 / 按章节当 checklist 反查
- 价值类型：流程模板 / 教学骨架 / 试玩方法
- 适用阶段：pre-production / prototype sprint / playtest loop / 课程与训练
