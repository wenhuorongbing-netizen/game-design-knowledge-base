# MIT OCW: Introduction to Game Design Methods (Spring 2016)

## 基本信息

- 作者：Mikael Jakobsson / Sara Verrilli
- 年份：2016
- 类型：course
- 来源：MIT OpenCourseWare

## 摘要

MIT 的方法论课程材料，包含 board game analysis、research、pitch、paper prototyping 和 playtest 等完整作业链。

## 核心要点

- 非常适合把知识库转成训练流程。
- 能直接沉淀成 prompt 和检查单。
- 对“做完一个原型后怎么验证”特别有帮助。

## 适用场景

最适合用于制作原型验证、试玩记录和审查模板。

## 分类

- 一级分类：测试、验收与审计
- 二级输出物：回归测试检查单
- 主题标签：试玩与迭代 / 设计基础 / 项目审计
- 可用性：已下载开放全文
