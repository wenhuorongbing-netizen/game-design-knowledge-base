# A Theory of Fun for Game Design：知识定位

## 这本书最适合解决什么

最适合在你需要判断一个系统为什么会令人持续投入、为什么会厌倦、以及玩家到底在学什么时介入。

## 主要关注

- 关注领域：乐趣理论 / 学习与模式 / 玩家成长 / 体验复盘
- 主要用途：体验判断 / 成长曲线讨论 / 设计哲学补课
- 推荐读法：按章通读 / 和系统设计并读 / 做设计复盘时回查
- 价值类型：理论框架 / 体验解释器 / 复盘语言
- 适用阶段：方向判断 / 体验复盘 / 高层设计训练
