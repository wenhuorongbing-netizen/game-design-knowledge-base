# Game Feel: A Game Designer's Guide to Virtual Sensation

## 基本信息

- 作者：Steve Swink
- 年份：2009
- 类型：book
- 来源：Routledge

## 摘要

从输入、响应、动画、音效、镜头和物理反馈等细部解释“手感”如何被构造出来，是把模糊体验拆回具体反馈层的经典书。

## 核心要点

- 它把“不爽”拆成可以修的具体反馈问题。
- 适合战斗、移动、交互、UI 响应和打击感表达。
- 它比纯美术方向更偏交互和控制体验。

## 适用场景

最适合在战斗、移动、操作反馈和镜头/音效表现层卡住时介入，而不是在高层方向阶段读完就结束。

## 知识定位

- 关注领域：输入反馈 / 打击感 / 动画响应 / 控制体验 / 交互美学
- 主要用途：打击感诊断 / 操作响应优化 / 体验层问题拆解
- 推荐读法：围绕具体动作反查 / 按案例拆读 / 和试玩录像一起看
