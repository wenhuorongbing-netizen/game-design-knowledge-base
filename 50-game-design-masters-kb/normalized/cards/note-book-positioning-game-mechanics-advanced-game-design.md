# Game Mechanics: Advanced Game Design：知识定位

## 这本书最适合解决什么

最适合处理资源产出消耗、战斗经济、成长循环、关卡-机制耦合和需要建模验证的系统，不适合只想要快速灵感时阅读。

## 主要关注

- 关注领域：mechanics / internal economy / Machinations / feedback loops / 系统平衡
- 主要用途：经济系统设计 / 数值框架分析 / 反馈回路审查 / 复杂系统建模
- 推荐读法：按章节通读 / 围绕具体系统反查 / 和自己的循环图并读
- 价值类型：建模工具 / 结构分析语言 / 平衡方法论
- 适用阶段：系统方案设计 / 数值框架搭建 / 中后期平衡 / 版本复盘
