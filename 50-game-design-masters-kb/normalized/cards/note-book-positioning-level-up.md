# Level Up! The Guide to Great Video Game Design：知识定位

## 这本书最适合解决什么

最适合在你已经有方向和机制，但需要把它们转成 spec、任务、关卡说明和跨团队沟通材料时介入。

## 主要关注

- 关注领域：设计文档 / 关卡与任务表达 / 制作沟通 / 商业开发流程
- 主要用途：spec 写作 / 交付物表达 / 跨职能沟通
- 推荐读法：按生产问题反查 / 写文档时并读 / 与 Workshop 结合使用
- 价值类型：落地模板 / 生产语言 / 表达桥梁
- 适用阶段：pre-production / production handoff / 文档整理
