# Game Design Concepts

## 基本信息

- 作者：Ian Schreiber
- 年份：2009
- 类型：course
- 来源：Game Design Concepts

## 摘要

Ian Schreiber 的开放课程，覆盖游戏定义、形式要素、机制与动态、乐趣、叙事、试玩、平衡和 UI。

## 核心要点

- 适合建立全团队共同语言。
- 特别适合原型、迭代和设计训练。
- 可直接映射到 prompt 体系中的立项、玩法、平衡和试玩类母类。

## 适用场景

最适合把泛泛系统讨论重新压回可验证机制和迭代流程。

## 分类

- 一级分类：核心玩法与系统设计
- 二级输出物：单机制原型设计
- 主题标签：设计基础 / 试玩与迭代 / Prompt 设计
- 可用性：已下载开放全文
