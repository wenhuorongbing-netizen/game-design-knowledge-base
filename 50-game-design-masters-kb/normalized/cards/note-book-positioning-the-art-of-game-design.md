# The Art of Game Design: A Book of Lenses：知识定位

## 这本书最适合解决什么

最适合在立项、方向收敛、设计评审、vertical slice 复盘和跨职能沟通时使用，而不是把它当成某一个单独系统的详细教程。

## 主要关注

- 关注领域：体验设计 / 玩家动机 / 迭代方法 / 界面与反馈 / 商业与伦理
- 主要用途：高层方向收敛 / 设计评审 / 跨团队对齐 / 问题清单构建
- 推荐读法：按章通读 / 按镜头反查 / 评审会前抽读
- 价值类型：问题框架 / 评审语言 / 跨学科地图
- 适用阶段：立项 / pre-production / vertical slice review / 上线后复盘
