# MIT OCW: Game Design (Spring 2014)

## 基本信息

- 作者：Philip B. Tan / Richard Eberhardt
- 年份：2014
- 类型：course
- 来源：MIT OpenCourseWare

## 摘要

MIT 的非数字游戏设计课，覆盖单机制、体验与美学、Perspective 以及规则写作规范。

## 核心要点

- 对规则表达非常有帮助。
- 适合把体验目标转回具体机制。
- 规则写作规范能直接用于项目文档质量提升。

## 适用场景

适合用来重写玩法规则、可读性规范和规则说明文档。

## 分类

- 一级分类：核心玩法与系统设计
- 二级输出物：单机制原型设计
- 主题标签：设计基础 / 规则与形式化 / 试玩与迭代
- 可用性：已下载开放全文
