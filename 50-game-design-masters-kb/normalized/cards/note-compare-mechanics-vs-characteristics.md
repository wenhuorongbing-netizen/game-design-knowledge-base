# Game Mechanics: Advanced Game Design vs Characteristics of Games

> Use Game Mechanics to model loops and internal economy, and use Characteristics of Games to describe uncertainty, information, and player effort precisely.

## Comparison Axis

- system modeling vs game-analysis vocabulary

## Game Mechanics: Advanced Game Design 更强在什么地方

- 经济系统设计
- 数值框架分析
- 反馈回路审查
- 复杂系统建模
- Use when: You need to model resources, progression, or feedback loops and want a system-level representation.

## Characteristics of Games 更强在什么地方

- 结构化拆解
- 规则审查
- 多人系统分析
- 分析语言
- Use when: You need a sharper language for rules, information exposure, multiplayer structure, and formal analysis.

## 如何一起使用

- Describe the system with Characteristics first, then model the loop behavior with Game Mechanics.
