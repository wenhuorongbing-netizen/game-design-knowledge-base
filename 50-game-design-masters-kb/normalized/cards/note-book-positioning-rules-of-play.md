# Rules of Play：知识定位

## 这本书最适合解决什么

最适合清理规则描述、系统边界、术语歧义和设计写作；当团队对“这个机制到底算什么”说不清时尤其有用。

## 主要关注

- 关注领域：规则理论 / 系统设计语言 / 玩法与意义 / 设计批评
- 主要用途：术语统一 / 规则审查 / 设计写作支撑
- 推荐读法：按结构通读 / 按术语反查 / 和项目文档并读
- 价值类型：基础框架 / 共通语言 / 形式化底座
- 适用阶段：立项 / 系统设计 / 文档标准化 / 设计复盘
