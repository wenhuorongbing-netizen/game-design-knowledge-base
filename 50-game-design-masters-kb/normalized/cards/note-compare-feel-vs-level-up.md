# Game Feel: A Game Designer's Guide to Virtual Sensation vs Level Up! The Guide to Great Video Game Design

> Use Game Feel to diagnose response quality and feedback timing, then use Level Up to express the resulting work as production-ready tasks and specs.

## Comparison Axis

- moment-to-moment sensation vs production-facing implementation language

## Game Feel: A Game Designer's Guide to Virtual Sensation 更强在什么地方

- 打击感诊断
- 操作响应优化
- 体验层问题拆解
- 诊断框架
- Use when: The game works mechanically, but movement, combat, or interaction still feels dead or muddy.

## Level Up! The Guide to Great Video Game Design 更强在什么地方

- spec 写作
- 交付物表达
- 跨职能沟通
- 落地模板
- Use when: The team understands the problem but needs concrete documentation, task framing, and implementation-facing language.

## 如何一起使用

- Let Game Feel define the sensory diagnosis, then let Level Up translate it into deliverables for the team.
