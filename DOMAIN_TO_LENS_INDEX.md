# Domain To Lens Index

Date: 2026-04-29

## Purpose

This index maps each master domain to diagnostic lenses. It lets the AI choose review questions before producing a workflow output.

All listed lenses are original KB diagnostic tools. They are not copied from books and are not verified source doctrine.

## Lens Selection Rule

Use project-direction lenses when the artifact is a concept.

Use mechanics, systems, game-feel, UI, or narrative lenses when the artifact is a specific design element.

Use prototype/playtest lenses when the artifact is an experiment or test plan.

Use AI-governance lenses whenever the AI is producing claims, summaries, or source-sensitive outputs.
