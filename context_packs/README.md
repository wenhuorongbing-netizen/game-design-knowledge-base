# Context Packs

Date: 2026-04-30

## What This Folder Is

This folder contains minimal context packs for using the Game Design Knowledgebase with an AI.

The goal is to avoid loading the whole repository.

## What This Folder Is Not

This folder is not:

- a source evidence folder;
- a benchmark output folder;
- a generated export folder;
- a schema folder;
- a private source folder.

## Recommended Default

Use [CP01_minimal_general_use.md](CP01_minimal_general_use.md) unless you know you need a task-specific pack.
