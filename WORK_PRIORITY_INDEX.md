# Work Priority Index

Date: 2026-04-29

## Purpose

This index ranks registered works for the Master Framework Phase. Priority is based on existing registry role, breadth across capabilities, usefulness for AI master behavior, and safe source status.

Priority does not mean the book has been ingested. Most works are metadata-only or prompt-referenced. Reading still requires the user to provide lawful notes or legal source evidence before claims can be promoted.

## Priority Definitions

| Priority | Meaning |
|---|---|
| `priority_1_foundational` | Read or annotate early because the work anchors multiple master capabilities. |
| `priority_2_practical` | Read next because it directly supports workflows, artifacts, prototyping, systems, or production practice. |
| `priority_3_specialized` | Read when focusing on a specific design domain such as play theory, character, ethics, or aesthetics. |
| `priority_4_reference` | Use as framework/history/reference routing until user notes or primary metadata exist. |
| `priority_5_later` | Defer until higher-priority works have notes or a specific need appears. |

## Recommended First Annotation Set

If the user wants maximum AI master-framework coverage with minimal initial note-taking, start with these five note packets:

1. The Art of Game Design: one note on lens use and one note on early concept review.
2. Game Design Workshop: one note on prototyping and one note on playtesting.
3. Game Mechanics: one note on mechanics/systems and one note on economy/balance.
4. A Theory of Fun: one note on fun/learning/player experience.
5. Rules of Play or MDA: one note on formal game structure.
