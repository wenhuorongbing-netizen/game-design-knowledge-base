# Tools

This folder contains the authoritative Game Design Knowledgebase tooling.

- Status: tool
- Users: maintainers and data engineers
- Edit: yes, only for tooling changes
- Updated by: human code changes; verify with `npm run kb:validate`

Authoritative commands from the repository root:

```powershell
npm run kb:export
npm run kb:validate
npm run kb:coverage
npm run kb:audit
```

Do not use `kb-tools/` as the default pipeline.
