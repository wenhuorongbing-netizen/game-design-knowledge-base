## Example Shape, Not Example Content

Do not copy this as evidence or project truth.

- Idea: one to five sentences about the game you actually want to explore.
- Target player: who the game is for, if known.
- Desired feeling: what the player should feel.
- Core action: what the player repeatedly does.
- Constraints: time, team size, platform, budget, or scope limits.

## What Codex Will Return

Codex will return a source-safe one-page concept memo with:

- one-sentence concept;
- player fantasy;
- core experience hypothesis;
- design pillars;
- key risks;
- next prototype question;
- assumptions;
- source_basis;
- confidence;
- evidence gaps;
- next action.
