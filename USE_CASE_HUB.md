# Use Case Hub

Date: 2026-04-30

## Purpose

This is the root-level hub for choosing how to use the Game Design Knowledgebase hands-on layer.

Use this file when you know what you want to do but do not know which prompt, context pack, worked example, or no-project path to open.

## What This Hub Is

This hub is:

- a first-use route selector;
- a bridge to copy-paste prompts;
- a bridge to minimal AI context packs;
- a bridge to synthetic worked examples;
- a bridge to no-project learning;
- a source-safety reminder.

## What This Hub Is Not

This hub is not:

- an app;
- a reading tracker;
- a forum;
- a source parser;
- a benchmark output;
- evidence that any claim is verified.

## Shortest Path

If you are unsure:

1. Open [USE_THIS_FIRST.md](USE_THIS_FIRST.md).
2. Open this hub.
3. Choose one row in the chooser table.
4. Load the matching context pack.
5. Copy the matching prompt.
6. Compare the result to a worked example if available.

## Default Trust Rule

Most first-use outputs are draft design scaffolds:

| Field | Default |
|---|---|
| source_basis | unsupported_draft for design scaffolds; metadata_only for book/work routing |
| confidence | weak |
| verified claims | none |
| evidence_refs | none unless explicitly supplied |
| project facts | none unless user supplies them |
| playtest facts | none unless user supplies them |

## Source Safety Rule

Do not ask AI to:

- parse private or high-risk source bodies;
- summarize private or copyrighted chapters;
- extract quotes from source files;
- invent citations;
- invent EvidenceRefs;
- invent user notes;
- invent legal sidecars;
- invent project facts;
- invent playtest observations.

For source-sensitive requests, use [context_packs/CP06_source_safety_and_claim_check.md](context_packs/CP06_source_safety_and_claim_check.md).
