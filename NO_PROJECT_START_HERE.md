# No-Project Start Here

Date: 2026-04-30

## Purpose

Use this path if you want the Game Design Knowledgebase to help you learn and practice game design before you have an active game project.

You do not need project evidence to start. You only need willingness to create small draft artifacts and label uncertainty.

## What This Path Is

This is a hands-on learning path for:

- learning game design concepts;
- practicing AI-assisted design thinking;
- creating small portfolio artifacts;
- building safe reading notes later;
- preparing for a future game project.

## What This Path Is Not

This is not:

- a fake project;
- a fake playtest;
- a source-backed masterclass;
- proof that an AI is master-ready;
- a private book summary workflow.

## Default Source And Confidence Rule

Unless you provide real user notes, legal evidence, project evidence, or playtest evidence:

| Field | Value |
|---|---|
| source_basis | unsupported_draft |
| confidence | weak |
| verified claims | none |
| project evidence | none |
| playtest evidence | none |

## What To Ask AI First

Use this prompt:

> Use the Game Design Knowledgebase as an AI Game Design Master learning coach. I do not have an active game project. Give me one small game design exercise for today, help me produce one draft artifact, and label assumptions, source_basis, confidence, evidence gaps, and what I must not overclaim.

## What You Should Produce First

Create one of these:

- one-sentence game concept;
- core experience statement;
- meaningful choice matrix;
- simple resource loop map;
- weak UI feedback redesign;
- paper prototype rule set;
- hypothetical playtest plan;
- pitch critique;
- unsupported claim check;
- learning reflection note.

## What Not To Overclaim

Do not claim:

- that a draft artifact proves a design works;
- that a hypothetical playtest is real;
- that a fictional project exists;
- that a book supports a claim without EvidenceRef;
- that player reactions are known without data;
- that the AI produced verified game design doctrine.
