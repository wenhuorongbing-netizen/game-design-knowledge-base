## What A User Can Do Today

- Start from one file.
- Choose a use case.
- Load one context pack.
- Copy one prompt.
- Paste a vague idea, learning goal, or claim.
- Receive one draft design artifact.
- Check assumptions, `source_basis`, confidence, and evidence gaps.

## What Is Not Proven

- Whether a first-time user starts in under 2 minutes without assistance.
- Whether the user chooses the right prompt on the first try.
- Whether users understand `source_basis` and confidence without a glossary.
- Whether the optional portal is accessible.
- Whether prompts produce high-quality target AI outputs in real use.

## Release Decision

Use the hands-on layer in a controlled observed trial. Do not add another navigation layer before testing.
