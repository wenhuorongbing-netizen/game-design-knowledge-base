# Book-Specific Note Prompts

Date: 2026-04-29

## Purpose

These prompts help the user create manual notes from specific works without asking the AI to read or summarize the books.

Every prompt below is a user-facing reading guide. It does not contain book summaries, chapter claims, quotations, or body-derived content.

## Universal Prompt Set

Use these questions for every reading note:

| Question | Purpose |
|---|---|
| What is the core idea? | Capture the user's own short paraphrase. |
| What design problem does this help solve? | Connect reading to production use. |
| What lens or diagnostic question does it suggest? | Convert reading into review behavior. |
| What workflow could it become? | Convert reading into action. |
| What example did you think of? | Capture user-generated application. |
| What do you disagree with? | Prevent passive summary and overclaiming. |
| What is still unclear? | Create evidence gaps. |
| What should AI not claim yet? | Preserve source governance. |
