# User Entrypoint Inventory

Date: 2026-04-30

## Purpose

This inventory classifies repository entrypoints by user intent. It is a usability baseline for reducing first-use confusion.

## Entrypoint Classes

| Class | Definition |
|---|---|
| user start | first file a non-maintainer can open |
| AI start | first file an AI agent should load |
| maintainer start | first file for repository maintenance |
| source governance start | first file for source/evidence safety |
| use case start | route from practical problem to prompt/context/example |
| prompt start | copy-paste prompt entry |
| context pack start | minimal AI context selection |
| benchmark start | target AI evaluation entry |
| ignore-first reference | file that tells users what to skip |

## Entrypoint Risk Assessment

| Risk | Severity | Note |
|---|---|---|
| too many start-like root files | P1 | `README.md`, `START_HERE.md`, `USE_THIS_FIRST.md`, `HANDS_ON_START_HERE.md`, and `HANDS_ON_START.md` compete |
| no observed time-to-start data | P1 | user trial is still pending |
| benchmark files are visually prominent | P2 | may distract from hands-on use |
| source governance docs are visible to casual users | P2 | necessary but intimidating |
| context-pack selection still requires judgment | P2 | CP01 default mitigates this |

## Recommended Default Entrypoint

For humans: `USE_THIS_FIRST.md`.

For immediate use: `10_MINUTE_QUICKSTART.md`.

For AI agents: `AI_CONTEXT_PACKS.md`.

For maintainers: `KB_REBUILD_INSTRUCTION.md`.
