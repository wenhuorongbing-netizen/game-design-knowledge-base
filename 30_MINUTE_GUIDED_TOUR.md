# 30 Minute Guided Tour

Use this when you want to understand the hands-on layer without reading the whole repository.

## Minute 0-5: Open The Right Files

Open:

1. [USE_THIS_FIRST.md](USE_THIS_FIRST.md)
2. [10_MINUTE_QUICKSTART.md](10_MINUTE_QUICKSTART.md)
3. [WHAT_TO_IGNORE_FIRST.md](WHAT_TO_IGNORE_FIRST.md)

Outcome: you know what this project is, what to do first, and what to ignore.

## Minute 5-10: Choose A Use Case

Open [USE_CASES/README.md](USE_CASES/README.md).

Pick one:

- no project yet;
- vague game idea;
- design review;
- learn game design;
- reading to notes;
- source safety check.

Outcome: you have one route and one prompt.

## Minute 10-15: Give AI Minimal Context

Open [AI_CONTEXT_MINIMUM.md](AI_CONTEXT_MINIMUM.md).

Tell the AI:

- this is Game Design Knowledgebase;
- use draft/source-governed scaffolding;
- do not parse private books;
- do not invent evidence;
- produce one artifact;
- label assumptions, `source_basis`, confidence, and evidence gaps.

Outcome: the AI has enough operating context to help safely.

## Minute 15-20: Run One Prompt

Copy a prompt from [COPY_PASTE_PROMPTS.md](COPY_PASTE_PROMPTS.md) or your use-case page.

Paste your idea, question, or learning goal.

Outcome: the AI produces a draft artifact.

## Minute 20-25: Check The Output

Compare the answer against [WORKED_EXAMPLES.md](WORKED_EXAMPLES.md).

Check:

- Did it produce an artifact?
- Did it ask too many questions?
- Did it label assumptions?
- Did it include `source_basis`?
- Did it include confidence?
- Did it avoid fake evidence and fake claims?

Outcome: you know whether the AI followed the runtime.

## Minute 25-30: Decide Your Next Action

Choose one:

| If the output is useful | Do this |
|---|---|
| You want to continue the idea | Ask for a second artifact. |
| You want to learn more | Ask for a mini lesson and exercise. |
| You want source support | Create user reading notes later. |
| You want project evidence | Wait until you have real project context. |
| The AI invented evidence | Reject the answer and rerun with source-safety rules. |

## What This Tour Does Not Do

It does not teach the whole repository, run validation, ingest evidence, or benchmark a target AI. It only gets you to hands-on use.
