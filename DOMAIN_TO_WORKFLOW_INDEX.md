# Domain To Workflow Index

Date: 2026-04-29

## Purpose

This index routes each master domain to practical workflow packs. It helps the AI move from domain diagnosis to concrete output artifacts.

Workflow packs are original production scaffolds and remain `unsupported_draft` until supported by user notes, project overlays, playtest logs, or legal evidence.

## Workflow Selection Rule

If a user gives only a vague idea, start with Game Idea to One-Page Concept Pack.

If a user gives a concrete mechanic, start with Rules and Formal Elements Pack or Meaningful Decision Audit Pack.

If a user gives an existing prototype, start with Prototype Question Pack, Game Feel Prototype Pack, UI Feedback Pack, or Playtest Plan Pack depending on the problem.

If a user asks for "make it better" without context, start with Design Lens Review Pack and ask for the artifact type.
