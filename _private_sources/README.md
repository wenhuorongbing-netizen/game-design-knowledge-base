# Private Source Quarantine

This folder is for local private source files only.

- Status: private/local
- Canonical: no
- Generated: no
- Git: ignored except this README
- Users: source auditor only
- Edit: no by default

Files in this folder are not part of the public Game Design Knowledgebase repository. They may include high-risk PDF, EPUB, archive, or scanned source files.

## Rules

- Do not parse source body text.
- Do not summarize chapters.
- Do not quote from these files.
- Do not generate embeddings from these files.
- Do not create verified claims from these files.
- Do not treat user possession as legal AI-processing permission.

Allowed operations without a legal sidecar:

- record filename;
- record visible/public metadata;
- attach user-provided notes;
- attach user-provided short manual quotes;
- mark as `metadata_only_quarantined` when high-risk markers are present.

Move a file out of this folder only after a source-governance review and an explicit legal sidecar or lawful replacement source exists.
