# Master Learning Path

Date: 2026-04-29

## Purpose

This path helps the user and the AI Master Framework learn game design by capability, not by book order.

The path is source-safe. It recommends works, concepts, lenses, workflows, exercises, note prompts, and output artifacts without summarizing private books or parsing source bodies.

## Source Governance

- Reading recommendations are routing guidance, not chapter summaries.
- High-risk or private sources remain metadata-only until legal sidecars or user notes exist.
- User notes should separate source claim, user interpretation, project idea, and AI hypothesis.
- The AI must not claim exact book arguments unless supported by legal evidence or user-provided notes.

## Capability Sequence

| Stage | Capability Focus | Why It Comes Here | Output Artifact |
|---|---|---|---|
| 1 | What is game design? | Establish design as decision-making, not idea generation only. | Designer decision inventory |
| 2 | Player experience and core experience | Define what players should feel, do, and understand. | Core experience statement |
| 3 | Formal elements, rules, mechanics | Turn intent into playable structure. | Formal elements sheet |
| 4 | Meaningful decisions | Make choices matter through information, tradeoff, and consequence. | Decision audit matrix |
| 5 | Skill, chance, challenge, balance | Tune difficulty, uncertainty, and fairness. | Challenge tuning memo |
| 6 | Systems, loops, economy | Understand parts, loops, feedback, resources, and progression. | System map |
| 7 | Play theory and playfulness | Understand play as context, attitude, constraint, and appropriation. | Play lens reflection |
| 8 | Game feel and feedback | Diagnose control, response, context, polish, and player perception. | Game feel audit |
| 9 | UI and interface | Make state, action, and consequence readable. | UI feedback audit |
| 10 | Narrative, world, character | Align story, role, world logic, and mechanics. | Narrative-mechanic alignment map |
| 11 | Prototyping | Convert assumptions into testable prototypes. | Prototype question sheet |
| 12 | Playtesting | Observe behavior and convert findings into decisions. | Playtest plan |
| 13 | Production, pitch, responsibility | Connect design to scope, communication, ethics, and release. | One-page pitch and risk memo |
| 14 | Master synthesis | Combine lenses, workflows, and teaching into expert AI behavior. | Capstone design review |

## How To Use This Path

1. Start with the 7-day plan if you are new.
2. Use the 30-day plan to build foundations.
3. Use the 90-day plan for a full structured pass.
4. Use the book sequence only after choosing a capability focus.
5. Create user notes every week; these notes are the safest path for upgrading the KB.

## Required Weekly Rhythm

- Read safely: use book metadata and user reading only; do not ask the AI to read private sources.
- Learn concepts: review relevant concept cards.
- Run lenses: ask diagnostic questions.
- Run workflows: produce one artifact.
- Practice: complete one exercise.
- Capture notes: write at least one user manual note.
- Try AI prompt: use the corresponding master prompt.
- Review confidence: mark what is draft, user interpretation, or evidence-backed.
