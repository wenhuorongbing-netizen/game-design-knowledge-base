## Purpose

Use this page when the repository feels too large and you want one practical path.

Pick the journey that matches your situation. Open only the files listed in that journey. Do not browse the whole repository.

## First-Time Rule

If you are not sure which journey to choose:

1. Open [JOURNEY_01_NO_PROJECT_LEARNING.md](JOURNEY_01_NO_PROJECT_LEARNING.md) if you have no project.
2. Open [JOURNEY_02_VAGUE_GAME_IDEA.md](JOURNEY_02_VAGUE_GAME_IDEA.md) if you have even a rough idea.
3. Open [JOURNEY_03_DESIGN_REVIEW.md](JOURNEY_03_DESIGN_REVIEW.md) if you already have a concept and want critique.

Stop there. Do not open governance, benchmark, schema, generated export, or evidence files unless the journey tells you to.

## Source And Confidence Default

For normal hands-on use, outputs are draft design help, not verified doctrine.

Default labels:

- source_basis: unsupported_draft
- confidence: weak
- verified claims: none
- evidence_refs: none unless real evidence is supplied and reviewed

## Accessibility Note

Each journey gives one next action. If a table is hard to scan, ignore the table and follow the "Next Action" section in the journey page.
