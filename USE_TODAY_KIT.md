# Use Today Kit

Date: 2026-04-30

## Purpose

This kit is the smallest normal-use surface for getting value from the Game Design Knowledgebase today.

Use it when you want to do something useful now, not maintain the repository.

## Open Only These First

1. [ONE_PAGE_LAUNCHPAD.md](ONE_PAGE_LAUNCHPAD.md)
2. [FIRST_ARTIFACT_MENU.md](FIRST_ARTIFACT_MENU.md)
3. [AI_CONTEXT_PACKS.md](AI_CONTEXT_PACKS.md)
4. one file under [hands_on_prompts/](hands_on_prompts/README.md)
5. [ACCESSIBLE_FIRST_USE_CHECKLIST.md](ACCESSIBLE_FIRST_USE_CHECKLIST.md)

## Do Not Open First

Do not open these for normal first use:

- generated exports;
- benchmark files;
- evidence records;
- source schemas;
- private source folders;
- deprecated material;
- legacy folders;
- validation internals.

## Default Trust Rule

Most first-use outputs are draft design help.

Unless real evidence is supplied:

- source_basis: unsupported_draft for design artifacts;
- source_basis: metadata_only for book or work routing;
- confidence: weak;
- verified claims: none;
- evidence_refs: none.

## What Good Use Looks Like

Good first use is simple:

1. choose one situation;
2. load one context pack;
3. copy one prompt;
4. paste one input;
5. receive one artifact;
6. check the labels;
7. take one next action.
