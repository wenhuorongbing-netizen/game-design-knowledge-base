# No-Project 7-Day Hands-On Plan

Date: 2026-04-30

## Purpose

This 7-day plan lets you use the KB immediately without an active game project.

Each day creates one small artifact. Treat all artifacts as draft practice unless real evidence is later supplied.

## Day-By-Day Plan

| Day | Focus | What to ask AI | Artifact | Read or inspect | Note to write | Exercise | What not to overclaim |
|---|---|---|---|---|---|---|---|
| 1 | one-sentence concept | Ask AI to help turn a theme into a one-sentence game concept. | one-sentence concept | USE_THIS_FIRST.md; worked example EX01 | why this concept interests you | write 5 concepts, choose 1 | do not claim the concept is viable |
| 2 | core experience | Ask AI to define player promise, feeling, and repeated action. | core experience statement | worked example EX02; MASTER_LEARNING_PATH.md stage 2 | what feeling you want players to have | rewrite the concept around one verb | do not claim players will feel it |
| 3 | meaningful choice | Ask AI to audit three choices for information, tradeoff, consequence. | meaningful choice matrix | worked example EX03; EXERCISE_SEQUENCE.md stage 4 | one choice that feels fake in a known game | make a choice matrix | do not claim it is meaningful until tested |
| 4 | resource loop | Ask AI to map a tiny resource loop with source, sink, feedback risk. | simple resource loop map | worked example EX04; EXERCISE_SEQUENCE.md stage 6 | one loop you noticed in a game | map energy, currency, or attention | do not claim it is balanced |
| 5 | feedback/UI | Ask AI to redesign one weak feedback signal. | feedback redesign table | worked example EX06; MASTER_DOMAIN_MAP.md UI section | one confusing feedback moment | redesign a warning or state signal | do not claim users will notice it |
| 6 | paper prototype | Ask AI to create a paper prototype rule set for one mechanic. | paper prototype rule set | CAPABILITY_UNLOCK_SEQUENCE.md prototyping row | what this prototype would test | define components, rules, win/fail state | do not claim test results exist |
| 7 | playtest plan and reflection | Ask AI to create a hypothetical playtest plan and learning reflection. | playtest plan plus reflection note | worked example EX09; USER_READING_NOTE_GUIDE.md | what you learned this week | write observation questions | do not invent participant behavior |

## Completion Checklist

By the end of 7 days, you should have:

- one concept;
- one core experience statement;
- one decision matrix;
- one resource loop map;
- one feedback redesign;
- one paper prototype rule set;
- one hypothetical playtest plan;
- one learning reflection note.

## Source And Confidence Rule

All seven-day artifacts default to:

- source_basis: unsupported_draft
- confidence: weak
- evidence_gap: no project, prototype, playtest, user note, or EvidenceRef yet
