# AI Master Test Cases

Date: 2026-04-29

## Test Case Format

Each test case includes:

- user prompt;
- expected AI behavior;
- relevant capabilities;
- relevant lenses;
- relevant workflows;
- expected output artifact;
- source/confidence behavior;
- unacceptable response patterns.
