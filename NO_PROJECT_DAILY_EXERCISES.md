# No-Project Daily Exercises

Date: 2026-04-30

## Purpose

These exercises let you practice game design without an active game project.

Each exercise produces a concrete artifact. None creates real project evidence or verified source claims.

## Exercise 1 - One-Sentence Game Concept

| Field | Content |
|---|---|
| input | a theme, feeling, genre, object, or verb |
| AI prompt | Help me turn this into five one-sentence game concepts. Label assumptions, source_basis, confidence, and evidence gaps. |
| output artifact | concept list with one selected concept |
| completion checklist | includes player, action, goal, feeling, and constraint |
| source/confidence rule | source_basis: unsupported_draft; confidence: weak |

## Exercise 2 - Core Experience

| Field | Content |
|---|---|
| input | one chosen concept |
| AI prompt | Define the core experience: player promise, repeated action, emotional target, and smallest proof. |
| output artifact | core experience statement |
| completion checklist | includes feeling, action, feedback, and testable question |
| source/confidence rule | do not claim players will feel this without testing |

## Exercise 3 - Meaningful Choice Matrix

| Field | Content |
|---|---|
| input | three possible player choices |
| AI prompt | Audit these choices for information, tradeoff, consequence, reversibility, and fake-choice risk. |
| output artifact | meaningful choice matrix |
| completion checklist | every choice has a tradeoff and consequence |
| source/confidence rule | source_basis: unsupported_draft; confidence: weak |

## Exercise 4 - Simple Resource Loop

| Field | Content |
|---|---|
| input | one resource such as energy, money, time, attention, food, or reputation |
| AI prompt | Map this resource as sources, sinks, feedback loops, hoarding risks, shortage risks, and test questions. |
| output artifact | source/sink loop map |
| completion checklist | identifies at least one source, sink, feedback risk, and balancing question |
| source/confidence rule | do not claim the loop is balanced without data |

## Exercise 5 - Weak UI Feedback Redesign

| Field | Content |
|---|---|
| input | one missed signal or confusing UI state |
| AI prompt | Redesign this feedback so the player can notice, interpret, and act on it. |
| output artifact | UI feedback redesign table |
| completion checklist | includes signal, timing, modality, player action, and risk |
| source/confidence rule | do not claim users will notice without usability evidence |

## Exercise 6 - Paper Prototype Rule Set

| Field | Content |
|---|---|
| input | one mechanic or choice |
| AI prompt | Create a paper prototype rule set with components, setup, turn structure, allowed actions, success/failure, and excluded scope. |
| output artifact | paper prototype rules |
| completion checklist | can be played in 10 minutes with simple materials |
| source/confidence rule | prototype is hypothetical until played |

## Exercise 7 - Hypothetical Playtest Plan

| Field | Content |
|---|---|
| input | one prototype question |
| AI prompt | Create a playtest plan without inventing results. Separate observed facts, interpretation, hypotheses, decisions, and next actions. |
| output artifact | playtest plan |
| completion checklist | includes goal, tasks, observation focus, questions, and what not to ask |
| source/confidence rule | no participant behavior exists until a real test happens |

## Exercise 8 - Pitch Critique

| Field | Content |
|---|---|
| input | one paragraph pitch, real or fictional |
| AI prompt | Critique this pitch for player promise, differentiation, scope, evidence gaps, and next proof. |
| output artifact | pitch critique memo |
| completion checklist | identifies promise, audience, proof gap, and rewrite |
| source/confidence rule | do not claim market demand |

## Exercise 9 - Unsupported Claim Check

| Field | Content |
|---|---|
| input | one design claim that sounds too certain |
| AI prompt | Check whether this claim is supported, unsupported, metadata-only, or unsafe to verify. Give safer wording. |
| output artifact | claim safety report |
| completion checklist | includes blocked wording, safer wording, evidence needed, and confidence |
| source/confidence rule | metadata_only and unsupported_draft cannot support verified claims |

## Exercise 10 - Learning Reflection Note

| Field | Content |
|---|---|
| input | one artifact you created this week |
| AI prompt | Help me write a learning reflection note that separates what I made, what I assumed, what I learned, what evidence is missing, and what AI must not claim. |
| output artifact | learning reflection note |
| completion checklist | includes artifact link, assumption, evidence gap, and next learning target |
| source/confidence rule | confidence: user_interpretation for your reflection; not verified source doctrine |
