# 10 Minute Quickstart

Use this when you want to get value from the KB immediately.

## Step 1: Choose A Use Case

Pick one:

| If you want to... | Use |
|---|---|
| shape a vague idea | [USE_CASES/vague_game_idea.md](USE_CASES/vague_game_idea.md) |
| get a design review | [USE_CASES/design_review.md](USE_CASES/design_review.md) |
| learn without a project | [USE_CASES/no_project_start.md](USE_CASES/no_project_start.md) |
| learn a concept | [USE_CASES/learn_game_design.md](USE_CASES/learn_game_design.md) |
| plan reading notes | [USE_CASES/reading_to_notes.md](USE_CASES/reading_to_notes.md) |
| check source safety | [USE_CASES/source_safety_check.md](USE_CASES/source_safety_check.md) |

## Step 2: Copy One Prompt

Use the prompt from the chosen use-case file, [HANDS_ON_PROMPT_LIBRARY.md](HANDS_ON_PROMPT_LIBRARY.md), or [COPY_PASTE_PROMPTS.md](COPY_PASTE_PROMPTS.md).

If you want to see a safe synthetic output before trying your own prompt, use [WORKED_EXAMPLES_README.md](WORKED_EXAMPLES_README.md).

## Step 3: Paste Your Idea Or Question

Replace bracketed text with your own idea, problem, concept, or question.

Keep it short. One paragraph is enough.

## Step 4: Ask AI To Produce An Artifact

Ask for one concrete artifact, such as:

- one-page concept memo;
- core experience statement;
- decision audit matrix;
- system map;
- economy source/sink table;
- game feel checklist;
- UI feedback audit;
- mini lesson and exercise;
- reading-note plan;
- evidence gap report.

## Step 5: Ask AI To Label Assumptions And Confidence

Require the AI to include:

- assumptions;
- `source_basis`;
- confidence;
- evidence gaps;
- what it must not claim;
- one next action.

## Step 6: Save The Output If Useful

Save useful output as:

- a draft design note;
- a future reading note prompt;
- a prototype question;
- a checklist;
- a decision log;
- a question for later playtesting.

Do not save it as verified evidence unless it has legal EvidenceRefs and review.

## 10-Minute Default Prompt

> Use the Game Design Knowledgebase as an AI Game Design Master runtime. I want a practical draft artifact, not verified book doctrine. Route my request, ask at most 3 missing-input questions only if needed, and produce one useful artifact with assumptions, `source_basis`, confidence, evidence gaps, and one next action.
>
> My request: [paste your idea or question]
