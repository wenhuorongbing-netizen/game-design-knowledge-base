# Minimum Questions

Date: 2026-05-01

## Status

blocked_pending_user_game_idea_packet

## Rule

Ask at most three high-value questions before proceeding.

The current workflow lacks the required idea packet, so the three questions should request only the missing required fields.

## Questions

1. What is the idea summary?
2. What desired player experience should the game create?
3. What current uncertainty or concern do you want Codex to help with?

## Optional Non-Blocking Details

The user may also provide:

- target player;
- genre;
- platform;
- constraints.

Do not block forever on optional fields if the three required fields are supplied.

## Do Not Ask Yet

Do not ask for:

- playtest results;
- source citations;
- private source files;
- legal sidecars;
- production estimates;
- telemetry.

Those are not needed for first concept routing.
