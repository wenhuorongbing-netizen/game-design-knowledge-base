# Journey 01 - No-Project Learning

Date: 2026-04-30

## Who This Is For

Use this if you want to learn game design but do not have a game project yet.

## When To Use It

Use this when you want practice, exercises, and learning artifacts without pretending you have real project evidence.

## What To Open First

Open:

1. [NO_PROJECT_START_HERE.md](NO_PROJECT_START_HERE.md)
2. [USE_CASES/no_project_start.md](USE_CASES/no_project_start.md)
3. [context_packs/CP03_learning_coach.md](context_packs/CP03_learning_coach.md)

Optional example:

## What Not To Open

Do not open these for first use:

- benchmark files;
- validation reports;
- generated exports;
- evidence sidecar folders;
- private source folders;
- schema files.

## Required Input

Bring one learning goal, such as:

- "I want to understand meaningful decisions."
- "I want to learn systems and economy basics."
- "I want a first exercise for game feel."

## Optional Input

You may add:

- your current skill level;
- a preferred genre;
- a book you want to read later;
- how much time you have today.

## Context Pack To Load

Load [context_packs/CP03_learning_coach.md](context_packs/CP03_learning_coach.md).

## Copy-Paste Prompt To Use

Use [hands_on_prompts/P12_teach_me_game_design.md](hands_on_prompts/P12_teach_me_game_design.md).

Copy its "Copy-Paste Prompt" section, replace the bracketed fields, and paste it into your AI.

## Expected Artifact

The AI should produce:

- a short lesson;
- 2 or 3 high-value questions;
- one exercise;
- one draft artifact to create;
- one next topic;
- source_basis and confidence labels.

## Good Output Checklist

A good output:

- gives you something to do immediately;
- avoids a long lecture;
- labels assumptions;
- labels source_basis and confidence;
- does not claim that synthetic practice is real project evidence;
- does not cite private books without evidence;
- ends with one clear next action.

## Accessibility Notes

If the prompt feels too long, ask the AI: "Give me the shortest version of this lesson and one exercise only."

Use headings and short lists in your AI output. Do not ask for a dense curriculum table on first use.

## Source/Confidence Rule

Treat the result as a learning scaffold.

Default:

- source_basis: unsupported_draft
- confidence: weak
- verified claims: none

## Common Confusion Points

- A hypothetical exercise is not a real project.
- A hypothetical playtest plan is not a real playtest result.
- A reading suggestion is not a chapter summary.
- You do not need evidence governance files for normal learning.
